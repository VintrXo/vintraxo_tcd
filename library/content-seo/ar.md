# @lesson content-seo-intent
title: نية البحث
summary: كلمة البحث تديك إشارة عن المهمة اللي الشخص عايز ينجزها.
---
كلمة البحث تديك إشارة عن المهمة اللي الشخص عايز ينجزها. «مثال Python لجمع أرقام» يناسبه شرح يشتغل فورًا، و«دورة Python للمبتدئين» يناسبه منهج وتكلفة وطريقة بداية. تعامل مع النية كفرضية واختبرها من صياغة السؤال ومحتوى النتائج.

## طبّق على إطلاق دورة Python

اكتب استعلامين من منظور موظف بيجهز تقريرًا. اقترح صفحة مختلفة لكل استعلام.

```quiz
? إيه أول حاجة تساعد الباحث عن مثال جمع؟
* مثال قصير قابل للتجربة
- سعر دورة فقط
- تاريخ الشركة
> المثال يلبّي المهمة اللي جاية في نص البحث.
```

# @lesson content-seo-plan
title: بناء خطة محتوى
summary: ابدأ بمشكلة واحدة متكررة.
---
ابدأ بمشكلة واحدة متكررة. اعمل صفحة شرح عملية، وصفحة دورة تشرح نطاق التعلّم، واربط بينهم برابط يوضّح وجهته. اكتب لكل قطعة جمهورًا، وسؤالًا تجيب عنه، ومثالًا تثبت به الفائدة، وموعدًا لمراجعتها.

## طبّق على إطلاق دورة Python

جهّز صفين في خطة: شرح جمع عمود، وصفحة دورة. حدّد سؤال كل صفحة قبل كتابة العنوان.

```quiz
? ما أنسب نص لرابط يوصّل للتمرين؟
- اضغط هنا
* جرّب جمع عمود باستخدام Python
- رقم ١
> النص يوضح المهمة والوجهة قبل الضغط.
```

# @lesson content-seo-landing
title: صفحة الهبوط وتحسين الظهور
summary: خلّي عنوان الصفحة يوضح العرض، واستخدم عنوانًا رئيسيًا متوافقًا معه.
---
خلّي عنوان الصفحة يوضح العرض، واستخدم عنوانًا رئيسيًا متوافقًا معه. قدّم مثالًا ودعوة واضحة للتسجيل، وهيكل المحتوى بعناوين. لو هدفك الظهور في البحث العام، اختبر إن الصفحة العامة قابلة للفتح بدون تسجيل وأن الرابط إليها قابل للزحف. قابلية الزحف تتيح الاكتشاف ولا تضمن الفهرسة.

## طبّق على إطلاق دورة Python

اكتب صفحة مسودة فيها عنوان، ومثال حساب بسيط، وزر «ابدأ أول درس». حدّد بالضبط اللي يحصل بعد الضغط.

```quiz
? أي عنوان أدق لصفحة شرح جمع الأرقام؟
- أفضل محتوى على الإنترنت
- Python Python Python
* اجمع أرقام تقرير باستخدام Python
> العنوان يصف الفائدة ومحتوى الصفحة بكلام طبيعي.
```

# @lesson content-seo-metrics
title: قياس انتقال القارئ للخطوة التالية
summary: حدّد مقياسًا مرتبطًا بهدف الصفحة.
---
حدّد مقياسًا مرتبطًا بهدف الصفحة. في شرح مجاني، ممكن يكون بدء المثال مقسومًا على زيارات الشرح. افصل هذا المؤشر عن التسجيل النهائي عشان تعرف هل القارئ استفاد من الشرح ثم هل قرر الانتقال للدورة.

## طبّق على إطلاق دورة Python

لو ٣٠ من ١٥٠ زائر بدأوا المثال، احسب المعدل. لو ٩ فقط سجّلوا، احسب التسجيل على زيارات نفس الصفحة.

```try python
visits = 150
for count in (30, 9):
    print(f"{count / visits:.0%}")
```

```quiz
? ما معدل بدء المثال؟
* 20%
- 6%
- 30%
> ٣٠ ÷ ١٥٠ = ٠٫٢٠. معدل التسجيل هنا ٦٪.
```

# @lesson content-seo-project
title: مشروع: خطة محتوى وصفحة تسجيل
summary: ابدأ من تقرير أسبوعي في حالة دورة Python.
---
ابدأ من تقرير أسبوعي في حالة دورة Python. جهّز شرحًا بمثال واحد وصفحة تسجيل فيها منهج مختصر ونتيجة من أول درس. اربط الشرح بالصفحة، واتفق مسبقًا على مقياس لكل خطوة. لاختبار الرسالة، غيّر عنوان الصفحة وحده واحتفظ بتوثيق النسختين.

## طبّق على إطلاق دورة Python

سلّم استعلامين مع نية كل واحد، ومسودة صفحتين، ونص الرابط، ومقياس البداية والتسجيل. اكتب تحديثًا واحدًا هتعمله لو بدأ ناس كتير المثال وعدد قليل انتقل للدورة.

```quiz
? إيه التغيير الواحد الأنسب لتشخيص خطوة الانتقال؟
- تغيير القناة والنص والسعر معًا
* اختبار نص الرابط للدورة مع تثبيت الشرح
- إيقاف القياس
> تغيير واحد يسهّل تفسير النتيجة.
```
