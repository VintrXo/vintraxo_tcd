# @lesson numerical-methods-bisection
title: التنصيف وضمان دقة التقريب
summary: ابدأ بفترة لدالة متصلة وإشارتين متضادتين عند الطرفين.
---
ابدأ بفترة لدالة متصلة وإشارتين متضادتين عند الطرفين. في كل خطوة جرّب المنتصف؛ لو لم يكن جذرًا احتفظ بالنصف الذي يحصر تغير الإشارة. بعد k خطوات يصبح طول الفترة الأولى مقسومًا على `2^k`، وخطأ المنتصف بالنسبة لجذر فيها لا يتجاوز نصف طولها.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
def f(x):
    return x * x * x - 2

left, right = 1.0, 2.0
for _ in range(8):
    middle = (left + right) / 2
    if f(middle) == 0:
        left = right = middle
        break
    if f(left) * f(middle) < 0:
        right = middle
    else:
        left = middle
print(round((left + right) / 2, 4))
print(round((right - left) / 2, 6))
```

```exercise
? لو طول الفترة 16، فما طولها بعد ثلاث عمليات تنصيف؟
___
= 2
```

```quiz
? لو طول الفترة بعد آخر خطوة 0.02، فكم الحد الأعلى لخطأ منتصفها؟
- 0.02
* 0.01
- 0.04
> أبعد نقطة عن المنتصف تكون عند طرف، على مسافة نصف طول الفترة.
```

# @lesson algorithmic-algebra-gcd
title: قاسم كثيرتي حدود
summary: على المعاملات النسبية، اقسم واستبدل الزوج بالمقسوم عليه والباقي وكرّر حتى يصبح الباقي صفرًا.
---
على المعاملات النسبية، اقسم واستبدل الزوج بالمقسوم عليه والباقي وكرّر حتى يصبح الباقي صفرًا. آخر كثيرة حدود غير صفرية، بعد قسمة معاملاتها على المعامل الرئيس، هي القاسم الموحّد. الكود هنا يخزّن المعاملات من الأقل درجة للأعلى لتسهيل طرح المضاعف المزاح.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction

def remainder(dividend, divisor):
    result = dividend.copy()
    while result and len(result) >= len(divisor):
        shift = len(result) - len(divisor)
        multiple = result[-1] / divisor[-1]
        for index, coefficient in enumerate(divisor):
            result[index + shift] -= multiple * coefficient
        while result and result[-1] == 0:
            result.pop()
    return result

a = list(map(Fraction, [-1, 0, 1]))
b = list(map(Fraction, [-1, 0, 0, 1]))
while b:
    a, b = b, remainder(a, b)
print([str(coefficient / a[-1]) for coefficient in a])
```

```exercise
? ما درجة كثيرة الحدود x³−1؟
___
= 3
```

```quiz
? ما القاسم الموحّد في المثال؟
- x+1
- x²−1
* x−1
> الترتيب التصاعدي [−1,1] يمثل x−1.
```

# @lesson algorithmic-algebra-interpolation
title: مشروع استيفاء لاغرانج
summary: تمر كثيرة حدود وحيدة درجتها أقل من n عبر n نقاط ذات مدخلات مختلفة.
---
تمر كثيرة حدود وحيدة درجتها أقل من n عبر n نقاط ذات مدخلات مختلفة. نستخدم لكل نقطة كثيرة حدود أساس تساوي واحدًا عند مدخلها وصفرًا عند بقية المدخلات، ونضربها في قيمة النقطة ثم نجمع. جرّب التحقق من النقاط الأصلية قبل إدخال نقطة جديدة.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction
from math import prod

points = [(0, 1), (1, 2), (2, 5)]

def interpolate(x):
    return sum(y * prod(Fraction(x - other, own - other)
                        for other, _ in points if other != own)
               for own, y in points)

print([str(interpolate(x)) for x, _ in points])
print(interpolate(Fraction(3, 2)))
```

```exercise
? ما قيمة الدالة عند المدخل 2؟
___
= 5
```

```quiz
? ليه المدخلات لازم تكون مختلفة؟
* لتجنّب مقام صفري
- عشان كل القيم تكون موجبة
- عشان تكون الدرجة n بالضبط
> مقام عامل الأساس هو فرق مدخلين.
```

summary: الاستراتيجية المختلطة توزيع احتمالات على الاختيارات.
---
الاستراتيجية المختلطة توزيع احتمالات على الاختيارات. في لعبة مطابقة العملة، لاعب الصف يكسب 1 عند التطابق ويخسر 1 عند الاختلاف. إذا اختار الخصم الصورة باحتمال p، فاختيار الصورة يعطي عائدًا متوقعًا `2p−1`، واختيار الكتابة يعطي `1−2p`.

# @lesson information-theory-conditional
title: الإنتروبي الشرطي
summary: الإنتروبي الشرطي `H(Y|X)` هو متوسط إنتروبي Y بعد معرفة X، بوزن كل قيمة لـX.
---
الإنتروبي الشرطي `H(Y|X)` هو متوسط إنتروبي Y بعد معرفة X، بوزن كل قيمة لـX. إذا حدد X قيمة Y، فلا يبقى غموض. الفرق `H(Y)−H(Y|X)` هو المعلومات المتبادلة.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
h_y = 1.0
conditional_entropy = {0: 0.0, 1: 0.0}
h_given_x = sum(0.5 * entropy for entropy in conditional_entropy.values())
print(h_given_x, h_y - h_given_x)
```

```exercise
? إذا كان Y يساوي X، فما قيمة H(Y|X)؟
___
= 0
```

```quiz
? لو X وY مستقلان وكان H(Y)=1، فما H(Y|X)؟
- 0
* 1
- 2
> مع الاستقلال، معرفة X لا تغيّر توزيع Y.
```

# @lesson information-theory-prefix
title: مشروع: قارن ترميزين
summary: في الترميز الخالي من البوادئ لا تبدأ كلمة ترميز بكلمة أخرى كاملة، فيسهل الفصل أثناء القراءة.
---
في الترميز الخالي من البوادئ لا تبدأ كلمة ترميز بكلمة أخرى كاملة، فيسهل الفصل أثناء القراءة. قارن أطوال ترميز ثابت من بتّين للرموز الثلاثة بترميز `0,10,11` يضع أقصر كلمة للرمز الأكثر تكرارًا.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
from fractions import Fraction

probabilities = [Fraction(1, 2), Fraction(1, 4), Fraction(1, 4)]
for codes in (['00', '01', '10'], ['0', '10', '11']):
    print(sum(p * len(code) for p, code in zip(probabilities, codes, strict=True)))
```

```exercise
? أي متوسط يعطيه الترميز القصير؟ اكتب كسرًا مثل 1/2.
___
= 3/2
```

```quiz

- نعم
- لو كان طول 01 زوجيًا فقط
* لا
> الكلمة 0 بادئة للكلمة 01.
```
