# @lesson applied-statistics-bayes
title: الاحتمال الشرطي وقاعدة بايز
summary: الاحتمال الشرطي يغيّر المجموعة التي نحسب داخلها.
---
الاحتمال الشرطي يغيّر المجموعة التي نحسب داخلها. في 100 طلب، 20 من الفرع A. تأخر 6 من A و4 من باقي الفروع. إذن احتمال التأخر داخل A هو `6/20`، واحتمال أن يكون الطلب من A إذا عرفنا أنه متأخر هو `6/10`. تعيد قاعدة بايز بناء الاحتمال الثاني بضرب الأول في `P(A)` ثم القسمة على `P(late)`.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from fractions import Fraction

p_a = Fraction(20, 100)
p_late_given_a = Fraction(6, 20)
p_late = Fraction(10, 100)
print(p_late_given_a)
print(p_late_given_a * p_a / p_late)
```

```exercise
? اكتب P(A | متأخر) كعدد عشري مثل 0.25.
___
= 0.6
```

```quiz
? ما المقام في P(متأخر | A) عند استخدام أعداد الطلبات؟
* 20
- 10
- 100
> الشرط يحصر الحساب في طلبات الفرع A.
```

# @lesson applied-statistics-binomial
title: التوزيع الثنائي
summary: لو كررت تجربة مستقلة n مرة مع نفس احتمال النجاح p، عدد النجاحات يتبع توزيعًا ثنائيًا.
---
لو كررت تجربة مستقلة n مرة مع نفس احتمال النجاح p، عدد النجاحات يتبع توزيعًا ثنائيًا. احتمال k نجاحات بالضبط يساوي `comb(n,k) × p^k × (1−p)^(n−k)`.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from math import comb

n, p = 3, 0.5
for k in range(n + 1):
    print(k, comb(n, k) * p ** k * (1 - p) ** (n - k))
```

```exercise
? كم ترتيبًا فيه نجاحان من ثلاث محاولات؟
___
= 3
```

```quiz
? ما احتمال ثلاثة نجاحات من ثلاث محاولات مستقلة عندما p = 0.5؟
- 0.375
* 0.125
- 0.5
> اضرب 0.5 في نفسها ثلاث مرات.
```

# @lesson applied-statistics-confidence
title: فترات الثقة
summary: لعينة مستقلة كبيرة، فترة Wald التقريبية لنسبة المجتمع هي النسبة المشاهدة ± `1.96 × SE` عند مستوى 95%.
---
لعينة مستقلة كبيرة، فترة Wald التقريبية لنسبة المجتمع هي النسبة المشاهدة ± `1.96 × SE` عند مستوى 95%. نجاح المنهج 95% معناه تغطية النسبة الحقيقية في نحو 95% من العينات المتكررة تحت الشروط المناسبة. هذا التقريب قد يضعف مع عينات صغيرة أو نسب قريبة من صفر أو واحد.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from math import sqrt

successes, n = 60, 100
observed = successes / n
margin = 1.96 * sqrt(observed * (1 - observed) / n)
print(round(observed - margin, 3), round(observed + margin, 3))
```

```exercise
? احسب الخطأ المعياري لو p = 0.5 وn = 100. اكتب الناتج عشريًا.
___
= 0.05
```

```quiz
? مع ثبات النسبة وتضاعف حجم العينة أربع مرات، ماذا يحدث لهامش الخطأ؟
- يتضاعف
- يبقى ثابتًا
* ينخفض للنصف
> الهامش يتناسب عكسيًا مع الجذر التربيعي للحجم.
```

# @lesson applied-statistics-test
title: اختبار الفرضيات
summary: نفترض أن احتمال الصورة في عملة هو 0.5 ونختبر البديل أنه أكبر.
---
نفترض أن احتمال الصورة في عملة هو 0.5 ونختبر البديل أنه أكبر. لو ظهر 7 صور من 8 رميات، فقيمة p أحادية الطرف هي احتمال 7 صور أو أكثر تحت الفرضية الصفرية. نقارنها بمستوى الدلالة المحدد مسبقًا.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from fractions import Fraction
from math import comb

n = 8
observed = 7
p_value = Fraction(sum(comb(n, k) for k in range(observed, n + 1)), 2 ** n)
print(p_value)
print(p_value < Fraction(5, 100))
```

```exercise
? كم احتمالًا متطرفًا من أصل 256 ترتيبًا لرميات المثال؟ اكتب البسط فقط.
___
= 9
```

```quiz
? ما الحالات الداخلة في الطرف في المثال؟
* 7 أو 8 صور
- 7 صور فقط
- صفر أو صورة واحدة
> البديل أنه أكبر، لذلك نعد النتائج المساوية للمشاهدة أو الأعلى منها.
```

# @lesson applied-statistics-regression
title: الانحدار الخطي البسيط
summary: خط المربعات الصغرى يختار الميل والمقطع لتصغير مجموع مربعات الفرق بين القيم المشاهدة والتوقعات.
---
خط المربعات الصغرى يختار الميل والمقطع لتصغير مجموع مربعات الفرق بين القيم المشاهدة والتوقعات. الميل يصف تغير التوقع لكل زيادة وحدة في المدخل. الارتباط وحده لا يثبت السبب، والتوقع بعيدًا عن نطاق البيانات يحتاج حذرًا.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from statistics import linear_regression

visits = [1, 2, 3, 4]
orders = [2, 3, 4, 5]
slope, intercept = linear_regression(visits, orders)
print(slope, intercept)
print(slope * 2.5 + intercept)
```

```exercise
? لو خط التوقع y = 2x + 1، ما توقعه عند x = 3؟
___
= 7
```

```quiz
? أي كمية يصغّرها خط المربعات الصغرى؟
- مجموع المشاهدات
* مجموع مربعات الأخطاء
- أكبر مدخل
> نربّع كل فرق بين القيمة الفعلية والمتوقعة ثم نجمع.
```

# @lesson applied-statistics-project
title: مشروع: قارن معدلات التأخر بين الفروع
summary: كل صف يمثل مجموعة طلبات فيها فرع وعدد كلي وعدد متأخر.
---
كل صف يمثل مجموعة طلبات فيها فرع وعدد كلي وعدد متأخر. جمّع الأعداد لكل فرع قبل حساب نسبة التأخر حتى يكون وزن كل طلب متساويًا. اذكر حجم كل مجموعة عند المقارنة لأن النسبة وحدها ممكن تخفي فرق العينة.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
import pandas as pd

rows = [('A', 12, 2), ('A', 8, 2), ('B', 20, 1), ('B', 10, 2)]
orders = pd.DataFrame(rows, columns=['branch', 'count', 'late'])
by_branch = orders.groupby('branch')[['count', 'late']].sum()
for branch, row in by_branch.iterrows():
    print(branch, row['count'], f"{row['late'] / row['count']:.0%}")
```

```exercise
? كم طلبًا متأخرًا في الفرع B؟
___
= 3
```

```quiz
? ليه بنقسم مجموع الطلبات المتأخرة على مجموع الطلبات لكل فرع؟
- عشان نتجاهل عدد الطلبات
- عشان نضمن تساوي الفرعين
* عشان كل طلب يكون له نفس الوزن
> متوسط نسب الصفوف مباشرةً قد يدي الصف الصغير وزنًا أكبر لكل طلب.
```
