# @lesson numerical-methods-error
title: الخطأ المطلق والنسبي
summary: الخطأ المطلق هو مقدار الفرق بين القيمة التقريبية والمرجعية.
---
الخطأ المطلق هو مقدار الفرق بين القيمة التقريبية والمرجعية. الخطأ النسبي يقسم الفرق المطلق على مقدار المرجع غير الصفري عشان يقارن أخطاء لمقاييس مختلفة.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
reference = 100
approximation = 98
absolute = abs(approximation - reference)
print(absolute)
print(absolute / abs(reference))
```

```exercise
? لو كانت القيمة المرجعية 40 والتقريب 42، فما الخطأ المطلق؟
___
= 2
```

```quiz
? متى تكون الصيغة المعتادة للخطأ النسبي غير معرّفة؟
* عند مرجع صفري
- عند تطابق التقريب والمرجع دائمًا
- عند تقليل الخطأ المطلق
> المقام هو مقدار القيمة المرجعية.
```

# @lesson numerical-methods-bisection
title: التنصيف وضمان دقة التقريب
summary: ابدأ بفترة لدالة متصلة وإشارتين متضادتين عند الطرفين.
---
ابدأ بفترة لدالة متصلة وإشارتين متضادتين عند الطرفين. في كل خطوة جرّب المنتصف؛ لو لم يكن جذرًا احتفظ بالنصف الذي يحصر تغير الإشارة. بعد k خطوات يصبح طول الفترة الأولى مقسومًا على `2^k`، وخطأ المنتصف بالنسبة لجذر فيها لا يتجاوز نصف طولها.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
def f(x):
    return x * x * x - 2

left, right = 1.0, 2.0
for _ in range(8):
    middle = (left + right) / 2
    if f(middle) == 0:
        left = right = middle
        break
    if f(left) * f(middle) < 0:
        right = middle
    else:
        left = middle
print(round((left + right) / 2, 4))
print(round((right - left) / 2, 6))
```

```exercise
? لو طول الفترة 16، فما طولها بعد ثلاث عمليات تنصيف؟
___
= 2
```

```quiz
? لو طول الفترة بعد آخر خطوة 0.02، فكم الحد الأعلى لخطأ منتصفها؟
- 0.02
* 0.01
- 0.04
> أبعد نقطة عن المنتصف تكون عند طرف، على مسافة نصف طول الفترة.
```

# @lesson numerical-methods-newton
title: طريقة نيوتن
summary: نقرّب الدالة بمماس عند التخمين x ونأخذ تقاطع المماس مع المحور كتخمين جديد `x−f(x)/f′(x)`.
---
نقرّب الدالة بمماس عند التخمين x ونأخذ تقاطع المماس مع المحور كتخمين جديد `x−f(x)/f′(x)`. الطريقة تحتاج مشتقة غير صفرية في الخطوة، والتقارب يعتمد على الدالة والتخمين الأول.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
guess = 2.0
for _ in range(3):
    guess -= (guess ** 2 - 2) / (2 * guess)
    print(round(guess, 6))
```

```exercise
? ما التخمين التالي بعد 2 في المثال؟ اكتب الناتج عشريًا.
___
= 1.5
```

```quiz
? ماذا يحدث للصيغة لو كانت المشتقة عند التخمين صفرًا؟
- يزيد التخمين دائمًا بمقدار 1
- يعطي الخطأ النسبي مباشرة
* لا يمكن استخدامها بهذه الخطوة
> المشتقة تقع في مقام كسر التحديث.
```

# @lesson numerical-methods-trapezoid
title: مشروع: قارن تقريبات شبه المنحرف
summary: قاعدة شبه المنحرف تستبدل المنحنى فوق كل جزء بخط يصل قيمتي طرفيه.
---
قاعدة شبه المنحرف تستبدل المنحنى فوق كل جزء بخط يصل قيمتي طرفيه. مساحة الجزء تقريبًا عرضه في متوسط ارتفاعي الطرفين. جرّبها لتكامل `x²` من 0 إلى 1، وقارن الخطأ بالنسبة للقيمة الدقيقة 1/3.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
def f(x):
    return x ** 2

for count in (2, 4, 8):
    width = 1 / count
    inside = sum(f(index * width) for index in range(1, count))
    area = width * (inside + (f(0) + f(1)) / 2)
    print(count, round(area, 6), round(abs(area - 1 / 3), 6))
```

```exercise
? ما عرض كل جزء لو قسمنا الفترة [0,1] لأربعة أجزاء متساوية؟
___
= 0.25
```

```quiz
? عند الانتقال من 2 إلى 8 أجزاء في المثال، ماذا يحدث للخطأ المطلق؟
* ينخفض
- يزيد
- يبقى ثابتًا
> التقريب يصبح أقرب إلى 1/3 في النتائج المعروضة.
```
