# @lesson calculus-limits
title: فكرة النهاية
summary: النهاية تصف القيمة التي تقترب منها الدالة عندما يقترب المدخل من عدد.
---
النهاية تصف القيمة التي تقترب منها الدالة عندما يقترب المدخل من عدد. التعبير `(x² − 1)/(x − 1)` يساوي `x + 1` عندما `x ≠ 1`، لذلك نهايته عند 1 هي 2 حتى مع كون التعبير الأصلي غير معرّف عند 1.

للمراجعة، ارجع إلى درس [[functions-ar/functions-slope|الميل والمقطع]].

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
for x in (0.9, 0.99, 1.01, 1.1):
    print(x, round((x ** 2 - 1) / (x - 1), 4))
```

```exercise
? إلى أي قيمة يقترب x + 4 عندما يقترب x من 2؟
___
= 6
```

```quiz
? لماذا لا نعوّض بـ x = 1 مباشرة في الكسر؟
* المقام يصبح صفرًا
- البسط يصبح واحدًا
- النهاية يجب أن تكون صفرًا
> نحسب سلوك التعبير بالقرب من 1 حيث المقام غير صفري.
```

# @lesson calculus-rate
title: من الميل المتوسط للميل اللحظي
summary: ميل القاطع بين نقطتين هو تغير الناتج على تغير المدخل.
---
ميل القاطع بين نقطتين هو تغير الناتج على تغير المدخل. عند تقريب النقطتين من بعضهما، يمكن أن يقترب ميل القاطع من ميل المماس. هذه النهاية، عندما توجد، هي المشتقة عند النقطة.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
def f(x):
    return x ** 2

x = 2
for h in (0.1, 0.01, 0.001):
    print(round((f(x + h) - f(x)) / h, 6))
```

```exercise
? ما متوسط معدل التغيّر في f(x) = x² من x = 1 إلى x = 3؟
___
= 4
```

```quiz
? لأي قيمة يقترب الميل عند x = 2 في المثال؟
- 2
* 4
- 8
> فرق المربعين مقسومًا على h يعطي 4 + h، فيقترب من 4.
```

# @lesson calculus-power
title: قاعدة القوى
summary: في كثيرات الحدود، مشتقة `xⁿ` للأس الصحيح الموجب `n` هي `n × xⁿ⁻¹`.
---
في كثيرات الحدود، مشتقة `xⁿ` للأس الصحيح الموجب `n` هي `n × xⁿ⁻¹`. اشتق كل حد مستقلًا، واضرب في معامله الأصلي. مشتقة الثابت صفر لأنه لا يتغير مع المدخل.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
def derivative(x):
    # Derivative of 3x² + 2x + 5
    return 6 * x + 2

for x in (0, 1, 2):
    print(x, derivative(x))
```

```exercise
? ما قيمة مشتقة x³ عند x = 2؟
___
= 12
```

```quiz
? ما مشتقة 4x³ − 2x + 7؟
- 4x² − 2
- 12x² − 2x + 7
* 12x² − 2
> نشتق الحدود إلى 12x² و−2 وصفر، ثم نجمع.
```

# @lesson calculus-optimize
title: أين تكون القيمة العظمى؟
summary: إذا تغيرت إشارة المشتقة من موجب إلى سالب عند نقطة داخلية، فالدالة تزيد قبلها وتقل بعدها.
---
إذا تغيرت إشارة المشتقة من موجب إلى سالب عند نقطة داخلية، فالدالة تزيد قبلها وتقل بعدها. عند البحث عن أكبر قيمة على فترة مغلقة، افحص الطرفين أيضًا. في المثال مساحة مستطيل محيطه 20 تساوي `w(10 − w)` ومشتقتها `10 − 2w`.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
def area(width):
    return width * (10 - width)

for width in (0, 4, 5, 6, 10):
    print(width, area(width))
```

```exercise
? ما عرض المستطيل عند أكبر مساحة؟
___
= 5
```

```quiz
? ما أكبر مساحة لمستطيل محيطه 20؟
* 25
- 24
- 20
> تساوي المشتقة صفرًا عند 5؛ المساحة هناك 5 × 5، وعند الطرفين صفر.
```

# @lesson calculus-integral
title: التكامل كمجموع مساحات
summary: لو كانت الدالة موجبة، نقدر نقرب المساحة تحت المنحنى بجمع مساحات مستطيلات ضيقة.
---
لو كانت الدالة موجبة، نقدر نقرب المساحة تحت المنحنى بجمع مساحات مستطيلات ضيقة. في المثال نستخدم القيمة عند الطرف الأيمن من كل جزء. عند زيادة عدد الأجزاء تقترب النتيجة من التكامل المحدد، وهو 1/2 للدالة `f(x) = x` من 0 إلى 1.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
for count in (4, 10, 100):
    width = 1 / count
    area = sum((index * width) * width for index in range(1, count + 1))
    print(count, round(area, 4))
```

```exercise
? ما المساحة تحت الدالة الثابتة f(x) = 3 من x = 0 إلى x = 4؟
___
= 12
```

```quiz
? لماذا تعطي المستطيلات اليمنى مساحة أكبر من المساحة الحقيقية للدالة x؟
- لأن عرض المستطيلات أكبر من عرض الفترة
* لأن قيمة الدالة عند كل طرف أيمن هي الأعلى في جزئه
- لأن الدالة تتناقص
> ارتفاع كل مستطيل يساوي أكبر ارتفاع للدالة داخل الجزء لأن الدالة متزايدة.
```

# @lesson calculus-distance
title: مشروع: احسب المسافة من السرعة
summary: جسم سرعته `2t + 1` متر في الثانية بين 0 و4 ثوانٍ.
---
جسم سرعته `2t + 1` متر في الثانية بين 0 و4 ثوانٍ. المسافة تساوي تكامل السرعة لأنها غير سالبة. دالة `t² + t` مشتقتها `2t + 1`، فنحسب فرق قيمها بين الطرفين. قارن المسافة الدقيقة بتقدير المستطيلات.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
def speed(time):
    return 2 * time + 1

def antiderivative(time):
    return time ** 2 + time

end = 4
count = 100
width = end / count
estimate = sum(speed(i * width) * width for i in range(1, count + 1))
print(antiderivative(end) - antiderivative(0))
print(round(estimate, 2))
```

```exercise
? ما المسافة من الثانية صفر إلى الثانية 3 بالمتر؟
___
= 12
```

```quiz
? ما وحدة ناتج تكامل السرعة المقاسة بالمتر في الثانية على الزمن بالثانية؟
- متر لكل ثانية
- متر مربع
* متر
> نضرب وحدة السرعة في وحدة الزمن، فتتبقى وحدة الطول.
```
