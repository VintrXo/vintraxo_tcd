# @lesson real-analysis-sequences
title: تقارب المتتاليات
summary: يتقارب `aₙ` إلى L إذا أمكن، لكل ε موجب، اختيار N يجعل `|aₙ−L|<ε` لكل `n≥N`.
---
يتقارب `aₙ` إلى L إذا أمكن، لكل ε موجب، اختيار N يجعل `|aₙ−L|<ε` لكل `n≥N`. للمتتالية `aₙ=2/n` اختر `N>2/ε`، فتحقق المتباينة لكل حد لاحق.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction

epsilon = Fraction(1, 10)
cutoff = 2 // epsilon + 1
print(cutoff)
print(Fraction(2, cutoff) < epsilon)
```

```exercise
? ما أصغر N لـ2/n<0.2 لكل n≥N؟
___
= 11
```

```quiz
? عند تطبيق تعريف التقارب، يجب أن ينطبق الشرط على كم حد بعد N؟
* كل n≥N
- الحد عند N فقط
- حد واحد أكبر من N
> الشرط يغطي ذيل المتتالية كله.
```

# @lesson real-analysis-continuity
title: الاستمرارية بتعريف إبسيلون ودلتا
summary: نقول إن f مستمرة عند a إذا أمكن جعل `|f(x)−f(a)|<ε` باختيار `|x−a|<δ`.
---
نقول إن f مستمرة عند a إذا أمكن جعل `|f(x)−f(a)|<ε` باختيار `|x−a|<δ`. للدالة `f(x)=3x+2`، الفرق في الناتج يساوي ثلاثة أضعاف فرق المدخل، فنختار `δ=ε/3`.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction

a = 2
epsilon = Fraction(3, 10)
delta = epsilon / 3
x = a + delta / 2
print(delta)
print(abs((3 * x + 2) - (3 * a + 2)) < epsilon)
```

```exercise
? لو ε=0.6 في المثال، فما قيمة δ حسب القاعدة؟ اكتبها عشريًا.
___
= 0.2
```

```quiz
? ماذا يحدث لفرق الناتج لو كان فرق المدخل أقل من δ؟
- يساوي ε دائمًا
* يكون أقل من ε
- يكون أكبر من ε
> فرق الناتج يساوي ثلاثة أضعاف فرق المدخل، وأقل من 3δ=ε.
```

# @lesson real-analysis-supremum
title: الحد الأعلى الأصغر
summary: الحد الأعلى لأي مجموعة يكون أكبر من أو يساوي كل عناصرها.
---
الحد الأعلى لأي مجموعة يكون أكبر من أو يساوي كل عناصرها. الحد الأعلى الأصغر هو أقل عدد له هذه الخاصية. للفترة `(0, 1)` هو 1، رغم أن 1 خارج الفترة، لأن كل عدد أصغر منه يترك فوقه عنصرًا من الفترة.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction

for denominator in (10, 100, 1000):
    point = 1 - Fraction(1, denominator)
    print(point, point < 1)
```

```exercise
? ما الحد الأعلى الأصغر للفترة (0, 5)؟
___
= 5
```

```quiz
? هل يوجد أكبر عنصر في الفترة (0, 1)؟
- نعم، 1
- نعم، 0
* لا
> لكل عنصر x في الفترة، تقع (x+1)/2 داخلها وهي أكبر منه.
```

# @lesson real-analysis-uniform
title: التقارب النقطي والمنتظم
summary: في التقارب المنتظم، نختار N واحدًا لكل المدخلات عند هامش ε ثابت.
---
في التقارب المنتظم، نختار N واحدًا لكل المدخلات عند هامش ε ثابت. الدوال `fₙ(x)=x/n` على `[0,1]` تتقارب بانتظام للصفر لأن الخطأ لا يتجاوز `1/n` في أي نقطة. التجربة الشبكية توضح الحد، والمتباينة تثبته لكل المدخلات.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
grid = [i / 10 for i in range(11)]
for n in (2, 10, 100):
    print(n, max(x / n for x in grid))
```

```exercise
? لو n=20، فما أكبر خطأ على [0,1]؟ اكتب الناتج عشريًا.
___
= 0.05
```

```quiz
? ما الذي يجب أن يكون مشتركًا لكل x عند التقارب المنتظم؟
* رقم البداية N عند هامش ثابت
- قيمة fₙ(x) دائمًا
- كل قيم x متساوية
> اختيار N لا يعتمد على x عند التقارب المنتظم.
```
