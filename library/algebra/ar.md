# @lesson algebra-variables
title: المتغيرات والتعويض
summary: المتغير رمز لقيمة.
---
المتغير رمز لقيمة. عند التعويض نستبدل الرمز بعدد ثم نطبق ترتيب العمليات. مثلًا قيمة `3x + 2` عند `x = 4` تساوي 14.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
x = 4
print(3 * x + 2)
```

```exercise
? احسب 2x + 1 عندما x = 5.
___
= 11
```

```quiz
? احسب 3x + 2 عندما x = −2.
- 8
* -4
- -8
> ثلاثة في سالب اثنين تساوي سالب ستة، ثم نضيف اثنين.
```

# @lesson algebra-terms
title: الحدود المتشابهة
summary: في `3x + 2x − 4` الحدّان الأولان لهما المتغير نفسه وبنفس الأس، فنجمع معامليهما لنحصل على `5x − 4`.
---
في `3x + 2x − 4` الحدّان الأولان لهما المتغير نفسه وبنفس الأس، فنجمع معامليهما لنحصل على `5x − 4`. الثابت يبقى مستقلًا.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
x = 3
print(3 * x + 2 * x - 4)
print(5 * x - 4)
```

```exercise
? ما معامل x بعد تبسيط 7x − 3x؟
___
= 4
```

```quiz
? أي تعبير يساوي 4x + 3 + 2x؟
- 9x
- 6x
* 6x + 3
> نجمع معاملي x ونُبقي الثابت 3.
```

# @lesson algebra-distribute
title: خاصية التوزيع
summary: نضرب كل حد داخل القوس في العامل خارجه.
---
نضرب كل حد داخل القوس في العامل خارجه. مثلًا `−2(x + 3) = −2x − 6`. انتبه لإشارة العامل مع كل حد.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
x = 5
print(-2 * (x + 3))
print(-2 * x - 6)
```

```exercise
? ما الحد الثابت بعد فك القوس في 4(x + 2)؟
___
= 8
```

```quiz
? أي تعبير يساوي −3(x − 2)؟
* −3x + 6
- −3x − 6
- −3x + 2
> سالب ثلاثة في سالب اثنين يساوي موجب ستة.
```

# @lesson algebra-equations
title: المعادلات الخطية
summary: المعادلة توازن بين طرفين.
---
المعادلة توازن بين طرفين. لحل `3x + 2 = 14` نطرح 2 من الطرفين ثم نقسمهما على 3. عوّض بالحل لتتأكد من الطرفين.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
x = (14 - 2) / 3
print(x)
print(3 * x + 2 == 14)
```

```exercise
? أوجد x من المعادلة 2x + 5 = 17.
___
= 6
```

```quiz
? أوجد x من المعادلة 4x − 3 = 9.
- 1.5
* 3
- 6
> أضف 3 إلى الطرفين لتحصل على 4x = 12.
```

# @lesson algebra-inequalities
title: المتباينات
summary: نقدر نجمع أو نطرح المقدار نفسه من الطرفين.
---
نقدر نجمع أو نطرح المقدار نفسه من الطرفين. عند الضرب أو القسمة على عدد سالب نعكس علامة المتباينة، ولذلك `−2x > 6` تعني `x < −3`.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
for x in (-5, -3, 0):
    print(x, -2 * x > 6, x < -3)
```

```exercise
? ما العدد الحدّي في حل x + 2 < 7؟
___
= 5
```

```quiz
? أي عبارة تكافئ −4x ≤ 8؟
- x ≤ −2
- x ≥ 2
* x ≥ −2
> القسمة على −4 تعكس العلامة وتحوّل 8 إلى −2.
```

# @lesson algebra-budget
title: مشروع: احسب ميزانية رحلة
summary: تكلفة الرحلة 30 ثابتة و8 لكل شخص، والميزانية 70.
---
تكلفة الرحلة 30 ثابتة و8 لكل شخص، والميزانية 70. كوّن المتباينة `30 + 8n ≤ 70`، ثم جرّب أكبر عدد صحيح يحققها وتحقق إن الشخص الإضافي يتجاوز الميزانية.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
budget = 70
fixed_cost = 30
per_person = 8
people = (budget - fixed_cost) // per_person
print(people)
print(fixed_cost + (people + 1) * per_person)
```

```exercise
? كم شخصًا يغطيهم النموذج إذا تغيرت الميزانية إلى 62؟
___
= 4
```

```quiz
? كم شخصًا كحد أقصى إذا كانت الميزانية 69؟
* 4
- 5
- 3
> يتبقى 39 بعد التكلفة الثابتة، وخمسة أشخاص يحتاجون 40.
```

# @lesson algebra-reference
title: مرجع أساسيات الجبر
summary: القواعد الأساسية مع أمثلة سريعة.
type: Reference
---
```reference
التعويض | استبدل المتغير بقيمته | 3x + 2 = 14 عند x = 4

المتباينة | اعكس العلامة عند القسمة على عدد سالب | −2x > 6 ⇔ x < −3
```
