# @lesson prog-what
title: ما هي البرمجة
summary: البرامج واللغات، وكيف ينفّذ الحاسوب التعليمات.
---
**البرنامج** قائمة تعليمات دقيقة ينفّذها الحاسوب خطوة بخطوة. و **البرمجة** هي كتابة هذه التعليمات بلغة يستطيع الحاسوب تشغيلها، مثل Python أو JavaScript أو Java.

الحاسوب سريع لكنه حرفي جدًا: ينفّذ ما كتبته بالضبط، لا ما كنت تقصده. وجزء كبير من البرمجة هو تعلّم التعبير بدقة عمّا تريد.

```try python
print("مرحبًا! هذا أول برنامج لي.")
print("2 + 3 =", 2 + 3)
print("انتهى.")
```

نفّذ الحاسوب ثلاث تعليمات من الأعلى إلى الأسفل. غيّر النص أو الأرقام وشغّله مرة أخرى؛ فالتجربة أسرع طريقة للتعلم.

:::info كيف تعمل هذه الدورة
تستخدم الأمثلة هنا لغة **Python** لأنها تُقرأ تقريبًا مثل الإنجليزية وتعمل داخل المتصفح مباشرة. والأفكار نفسها (المتغيرات والقرارات والحلقات والدوال) موجودة في كل لغة ستتعلمها لاحقًا.
:::

```quiz
? ما هو البرنامج؟
* قائمة تعليمات دقيقة ينفّذها الحاسوب
- شاشة الحاسوب
- نوع من اتصال الإنترنت

? ينفّذ الحاسوب ما كنت تقصده حتى لو كتبت شيئًا مختلفًا قليلًا.
= false
> ينفّذ الحاسوب التعليمات كما كُتبت بالضبط، ولهذا تهم دقة التعليمات.
```

# @lesson prog-algorithms
title: الخوارزميات والتفكير بالخطوات
summary: تقسيم المشكلة إلى خطوات واضحة، والكود الوصفي، والمخططات الانسيابية.
---
**الخوارزمية** وصفة خطوة بخطوة لحل مشكلة. وقبل كتابة الكود يكتب المبرمجون الجيدون الخطوات غالبًا بكلمات عادية تُسمى **الكود الوصفي (pseudocode)**.

المشكلة: إيجاد أكبر رقم في قائمة.

```text
ابدأ بالرقم الأول على أنه "الأكبر"
لكل رقم آخر:
    إذا كان أكبر من "الأكبر":
        يصبح هو "الأكبر" الجديد
في النهاية "الأكبر" هو الإجابة
```

نفس الخوارزمية في Python:

```try python
numbers = [12, 45, 7, 89, 23]
largest = numbers[0]
for n in numbers:
    if n > largest:
        largest = n
print("أكبر رقم هو", largest)
```

**المخطط الانسيابي (flowchart)** يرسم الخطوات نفسها كمستطيلات (أفعال) ومعيّنات (أسئلة بأسهم نعم/لا). الكود الوصفي والمخططات الانسيابية يساعدانك على التخطيط قبل الكتابة.

:::tip قسّمها
إذا بدت المشكلة كبيرة جدًا فقسّمها: "اصنع تطبيق اختبارات" تصبح "خزّن الأسئلة" و"اعرض سؤالًا" و"تحقّق من الإجابة" و"احسب النتيجة". وكل خطوة صغيرة سهلة البرمجة.
:::

```quiz

- نوع من الحواسيب
- لغة برمجة
```


# @lesson prog-operators
title: العمليات والتعبيرات
summary: الحساب والمقارنات ودمج الشروط بـ and و or و not.
---
```try python
a = 17
b = 5
print("المجموع", a + b, "الفرق", a - b)
print("الضرب", a * b, "القسمة", a / b)
print("القسمة الصحيحة", a // b, "الباقي", a % b)
print("الأس", 2 ** 8)

print(a > b, a == b, a != b)       # المقارنات تعطي True أو False
age = 20
has_ticket = True
print(age >= 18 and has_ticket)    # يجب أن يتحقق الشرطان
print(age < 12 or age > 65)        # يكفي تحقق شرط واحد
print(not has_ticket)

greeting = "مرحبًا، " + "يا عالم"     # علامة + تدمج النصوص

```

```reference python
+ - * / | الحساب | 7 / 2 تعطي 3.5
// / % | القسمة الصحيحة / الباقي | 7 % 2 تعطي 1
** | الأس | 2 ** 3 تعطي 8
== != < > <= >= | المقارنات (تعطي True/False) | age >= 18
and / or / not | دمج الشروط | x > 0 and x < 10
+ مع النصوص | دمج النصوص | "a" + "b" تعطي "ab"
```

:::

# @lesson prog-loops
title: الحلقات
summary: تكرار العمل بـ for و while، والعدّ والجمع داخل الحلقة.
---
**الحلقة** تكرر التعليمات، فلا تحتاج لكتابتها مرة بعد مرة.

```try python
for i in range(1, 6):              # 1 و 2 و 3 و 4 و 5
    print("الجولة", i)

shopping = ["خبز", "حليب", "بيض"]
for item in shopping:
    print("اشترِ", item)

total = 0
for price in [12, 30, 8]:
    total = total + price          # نجمع أثناء المرور
print("الإجمالي:", total)

count = 3
while count > 0:                   # كرر ما دام الشرط صحيحًا
    print(count)
    count = count - 1
print("انطلق!")

for n in range(1, 20):
    if n % 7 == 0:
        print("أول مضاعف للعدد 7:", n)
        break                      # أوقف الحلقة مبكرًا
```

```reference python
for x in list | افعل شيئًا لكل عنصر | for name in names:
range(a, b) | الأرقام من a حتى b-1 | range(1, 11)
while condition | كرر ما دام الشرط صحيحًا | while lives > 0:
break | اخرج من الحلقة الآن | if found: break
continue | انتقل للدورة التالية | if n < 0: continue
```

:::warning الحلقات اللانهائية
إذا لم يصبح شرط `while` خاطئًا أبدًا فلن تتوقف الحلقة. تأكد أن شيئًا داخل الحلقة يغيّر الشرط، مثل `count = count - 1` في المثال.
:::


# @lesson prog-debugging
title: الأخطاء وتصحيحها
summary: قراءة رسائل الخطأ، والأخطاء الشائعة، وإيجاد الأخطاء خطوة بخطوة.
---
كل مبرمج يخطئ. **الخلل (bug)** خطأ في البرنامج، و **التصحيح (debugging)** هو إيجاده وإصلاحه.

هناك ثلاثة أنواع من الأخطاء:

1. **أخطاء الصياغة**: الكود يخالف قواعد اللغة (نسيان `:` أو قوس)، فلا يبدأ البرنامج.
2. **أخطاء التشغيل**: يبدأ الكود لكن يحدث شيء مستحيل، مثل القسمة على صفر.
3. **أخطاء المنطق**: يعمل البرنامج لكنه يعطي إجابة خاطئة.

```try python
prices = [10, 20, 30]

try:
    print(prices[3])                  # لا يوجد عنصر رابع
except IndexError as error:
    print("خطأ تشغيل:", error)

try:
    print(100 / 0)
except ZeroDivisionError as error:
    print("خطأ تشغيل:", error)

# خطأ منطقي: يجب أن يكون المتوسط 20
total = 0
for p in prices:
    total = total + p
average = total / 2                   # خلل: يجب القسمة على len(prices)
print("المتوسط (خطأ):", average)
print("المتوسط (بعد الإصلاح):", total / len(prices))

# اطبع القيم لترى ما يحدث
for i, p in enumerate(prices):
    print("الخطوة", i, "السعر", p)
```

:::tip كيف تصحّح الأخطاء
اقرأ رسالة الخطأ: فهي تسمّي المشكلة والسطر. ثم اطبع القيم لترى ما يراه البرنامج فعلًا، واختبر بمدخلات صغيرة تعرف إجابتها، وغيّر شيئًا واحدًا في كل مرة.
:::

```quiz
- خطأ تشغيل
```

# @lesson prog-project
title: مشروع: حاسبة الدرجات
summary: المتغيرات والقوائم والحلقات والقرارات والدوال في برنامج صغير واحد.
---
يأخذ البرنامج التالي نتائج فصل دراسي، ويحسب متوسط كل طالب وتقديره، ويطبع تقريرًا قصيرًا.

```try python
def average(numbers):
    return sum(numbers) / len(numbers)

def letter(avg):
    if avg >= 90:
        return "A"
    elif avg >= 80:
        return "B"
    elif avg >= 65:
        return "C"
    elif avg >= 50:
        return "D"
    return "F"

results = {
    "سارة": [95, 88, 92],
    "عمر": [72, 65, 80],
    "لينا": [45, 52, 38],
}

passed = 0
best_name, best_avg = None, -1
for name, marks in results.items():
    avg = average(marks)
    grade = letter(avg)
    print(f"{name:6} المتوسط {avg:5.1f}  التقدير {grade}")
    if grade != "F":
        passed += 1
    if avg > best_avg:
        best_name, best_avg = name, avg

print("الناجحون:", passed, "من", len(results))
print("الأول على الفصل:", best_name)
```

:::tip اجعله مشروعك
أضف طالبًا جديدًا، أو غيّر حدود التقديرات، أو اطبع متوسط الفصل. ثم أضف قاعدة: الطالب الذي لديه أي درجة أقل من 40 يجب أن يعيد المادة.
:::

```quiz
? لماذا كُتبت average و letter كدالتين منفصلتين؟
* لأن كلًا منهما تؤدي مهمة واضحة ويمكن إعادة استخدامها واختبارها وحدها
- لأن Python تشترط وجود دالتين في كل برنامج
- لأن الدوال تجعل البرنامج أسرع
```
