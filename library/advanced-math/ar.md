# @lesson advanced-math-measure
title: نظرية القياس
summary: القياس يعمّم فكرة الطول.
---
القياس يعمّم فكرة الطول. طول الفترة `[a, b)` يساوي `b − a`. لو الفترات متباينة، نجمع أطوالها لقياس اتحادها. الدالة البسيطة تأخذ عددًا محدودًا من القيم، وتكاملها يجمع كل قيمة مضروبة في قياس الجزء الذي تأخذها عليه.

لو محتاج مراجعة، ارجع لدرس [[math-branches-ar/math-branches-analysis|التحليل الحقيقي]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
pieces = [(0, 2, 3), (2, 5, 4)]
length = sum(right - left for left, right, _ in pieces)
integral = sum((right - left) * value for left, right, value in pieces)
print(length, integral)
```

```exercise
? ما طول اتحاد [0, 2) و[4, 7)؟
___
= 5
```

```quiz
? إذا أخذت الدالة القيمة 3 على [0, 2) والقيمة 4 على [2, 5)، فما تكاملها على [0, 5)؟
* 18
- 12
- 20
> نحسب 3 × 2 + 4 × 3.
```

# @lesson advanced-math-functional
title: التحليل الدالي
summary: يدرس التحليل الدالي فضاءات فيها المتجهات ممكن تكون دوال.
---
يدرس التحليل الدالي فضاءات فيها المتجهات ممكن تكون دوال. معيار القيمة العظمى لدالة مستمرة على فترة مغلقة هو أكبر قيمة لـ`|f(x)|`. المسافة بهذا المعيار بين دالتين هي معيار الفرق بينهما. في المثال `f(x)=x` و`g(x)=x²` على `[0, 1]`، والفرق يبلغ أقصاه عند النصف.

لو محتاج مراجعة، ارجع لدرس [[linear-algebra-ar/linear-algebra-vectors|المتجهات والمركبات]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
points = [i / 100 for i in range(101)]
gaps = [(abs(x - x ** 2), x) for x in points]
gap, location = max(gaps)
print(location, gap)
```

```exercise
? ما معيار القيمة العظمى للدالة الثابتة −3؟ اكتب المقدار الموجب.
___
= 3
```

```quiz
? ماذا تقيس المسافة بين دالتين بهذا المعيار؟
- متوسط الفرق
* أكبر فرق مطلق
- أصغر فرق مطلق
> نأخذ أكبر قيمة مطلقة للفرق على الفترة. في المثال `x − x² = 1/4 − (x − 1/2)²`.
```

# @lesson advanced-math-curvature
title: الهندسة التفاضلية
summary: يدرس هذا الفرع الأشكال بأدوات التفاضل.
---
يدرس هذا الفرع الأشكال بأدوات التفاضل. انحناء المنحنى يقيس سرعة تغير اتجاه المماس لكل وحدة طول على المنحنى. للدائرة ذات نصف القطر `r` الانحناء ثابت ويساوي `1/r`، لأن المماس يدور دورة كاملة على مسافة `2πr`.

لو محتاج مراجعة، ارجع لدرس [[calculus-ar/calculus-rate|الميل اللحظي]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from math import pi

for radius in (1, 2, 4):
    turn = 2 * pi
    length = 2 * pi * radius
    print(radius, round(turn / length, 2))
```

```exercise
? ما انحناء دائرة نصف قطرها 5؟ اكتب الناتج عشريًا.
___
= 0.2
```

```quiz
? لو ضاعفنا نصف القطر، ماذا يحدث للانحناء؟
- يتضاعف
- لا يتغير
* ينخفض للنصف
> الانحناء يساوي مقلوب نصف القطر.
```

# @lesson advanced-math-heat
title: المعادلات التفاضلية الجزئية
summary: درجة الحرارة في قضيب تعتمد على المكان والزمن.
---
درجة الحرارة في قضيب تعتمد على المكان والزمن. معادلة الحرارة في بعد واحد تربط معدل تغير الحرارة مع الزمن بالمشتقة الثانية في المكان. على شبكة نقاط نقرب التأثير بمقارنة كل نقطة بجارَيها، ومع معامل 0.25 نضيف ربع الفرق الثاني في كل خطوة. في المثال الطرفان مثبتان عند الصفر.

لو محتاج مراجعة، ارجع لدرس [[math-branches-ar/math-branches-differential|المعادلات التفاضلية]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
current = [0, 0, 100, 0, 0]
for _ in range(2):
    updated = current.copy()
    for i in range(1, len(current) - 1):
        difference = current[i - 1] - 2 * current[i] + current[i + 1]
        updated[i] = current[i] + 0.25 * difference
    current = updated
    print(current)
```

```exercise
? في المثال، ما قيمة النقطة الوسطى بعد الخطوة الأولى؟
___
= 50
```

```quiz
? ليه بنحسب قيم الخطوة الجديدة من القائمة القديمة؟
* كل النقاط تتحدث من الحالة نفسها
- لتجاهل الجيران
- لتغيير قيم الأطراف
> تحديث نقطة قبل استعمالها لجارتها يخلط بين زمنين مختلفين.
```

# @lesson advanced-math-physics
title: الفيزياء الرياضية
summary: في النموذج المثالي لكتلة على زنبرك، نفترض أن القوة `−kx` ونستبعد الاحتكاك.
---
في النموذج المثالي لكتلة على زنبرك، نفترض أن القوة `−kx` ونستبعد الاحتكاك. الطاقة الكلية هي مجموع طاقة الحركة `mv²/2` وطاقة الزنبرك `kx²/2`. عند أقصى إزاحة تكون السرعة صفرًا، وعند عبور موضع الاتزان تنتقل الطاقة كلها إلى الحركة.

لو محتاج مراجعة، ارجع لدرس [[math-branches-ar/math-branches-differential|المعادلات التفاضلية]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from math import sqrt

mass = 1
stiffness = 4
amplitude = 0.5
energy = stiffness * amplitude ** 2 / 2
speed_at_equilibrium = sqrt(2 * energy / mass)
print(energy, speed_at_equilibrium)
```

```exercise
? ما طاقة الزنبرك لو k = 4 والإزاحة x = 1؟
___
= 2
```

```quiz
? ماذا يحدث للطاقة الكلية في هذا النموذج؟
- تساوي صفرًا عند الاتزان
* تبقى ثابتة
- تتضاعف كل دورة
> الطاقة تتحول بين حركة وطاقة وضع عند غياب الاحتكاك.
```

# @lesson advanced-math-combinatorics
title: التوافقيات المتقدمة
summary: مبدأ الشمول والاستبعاد يصحح العدّ المكرر.
---
مبدأ الشمول والاستبعاد يصحح العدّ المكرر. عند عدّ اتحاد ثلاث مجموعات، اجمع أحجامها، ثم اطرح أحجام التقاطعات الثنائية، ثم أضف حجم التقاطع الثلاثي. كده العضو الموجود في المجموعات الثلاث يُحسب مرة واحدة.

لو محتاج مراجعة، ارجع لدرس [[discrete-math-ar/discrete-math-combinations|التباديل والتوافيق]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
numbers = range(1, 31)
a = {n for n in numbers if n % 2 == 0}
b = {n for n in numbers if n % 3 == 0}
c = {n for n in numbers if n % 5 == 0}
count = len(a) + len(b) + len(c)
count -= len(a & b) + len(a & c) + len(b & c)
count += len(a & b & c)
print(count, len(a | b | c))
```

```exercise
? لو كانت مجموعة فيها 8 عناصر والثانية 5 وبينهما عنصران مشتركان، فكم عنصرًا في الاتحاد؟
___
= 11
```

```quiz
? ماذا نفعل بحجم التقاطع الثلاثي بعد طرح التقاطعات الثنائية؟
- نطرحه مرة أخرى
- نتجاهله دائمًا
* نضيفه مرة واحدة
> العنصر في التقاطع الثلاثي أُضيف ثلاث مرات وطُرح ثلاث مرات، فنضيفه مرة ليظهر في الاتحاد.
```

# @lesson advanced-math-categories
title: نظرية الفئات
summary: تدرس نظرية الفئات الكائنات والأسهم وطريقة تركيبها.
---
تدرس نظرية الفئات الكائنات والأسهم وطريقة تركيبها. في مثال مألوف، المجموعات هي الكائنات والدوال بينها هي الأسهم. لكل مجموعة دالة هوية. التركيب تجميعي: لما الأنواع تتوافق، `h ∘ (g ∘ f)` يساوي `(h ∘ g) ∘ f`، والصيغتان تطبّقان f ثم g ثم h.

لو محتاج مراجعة، ارجع لدرس [[functions-ar/functions-rule|مدخلات الدالة ومخرجاتها]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
def compose(g, f):
    return lambda x: g(f(x))

def f(x):
    return x + 1

def g(x):
    return 2 * x

def h(x):
    return x - 3

left = compose(h, compose(g, f))
right = compose(compose(h, g), f)
print(left(4), right(4))
```

```exercise
? لو f(x) = x + 1 وg(x) = 2x، فما قيمة (g ∘ f)(3)؟
___
= 8
```

```quiz
? أي دالة تمثل الهوية على مجموعة الأعداد الصحيحة؟
* x ↦ x
- x ↦ x + 1
- x ↦ 0
> دالة الهوية تعيد المدخل نفسه لكل عدد.
```
