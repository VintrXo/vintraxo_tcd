# @lesson combinatorics-inclusion
title: الشمول والاستبعاد
summary: اتحاد مجموعتين يساوي مجموع العدّين ناقص التقاطع.
---
اتحاد مجموعتين يساوي مجموع العدّين ناقص التقاطع. مع ثلاث مجموعات نطرح التقاطعات الثنائية ثم نضيف التقاطع الثلاثي. النمط يصحح عدّ كل عنصر وفق عدد المجموعات التي تحتويه.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
values = range(1, 21)
a = {n for n in values if n % 2 == 0}
b = {n for n in values if n % 3 == 0}
print(len(a), len(b), len(a & b), len(a | b))
```

```exercise
? لو |A|=10 و|B|=6 و|A∩B|=3، فكم حجم الاتحاد؟
___
= 13
```

```quiz
? ليه نطرح حجم التقاطع مرة واحدة؟
* كل عنصر مشترك اتحسب مرتين
- كل عنصر مشترك اتحسب صفر مرات
- لأن الاتحاد يحتوي التقاطع فقط
> طرح نسخة واحدة يترك لكل عنصر مشترك نسخة واحدة.
```

# @lesson combinatorics-pigeonhole
title: مبدأ صندوق الحمام
summary: لو وزّعنا `n` عنصرًا على `k` صناديق، يوجد صندوق فيه على الأقل `ceil(n/k)` عنصر.
---
لو وزّعنا `n` عنصرًا على `k` صناديق، يوجد صندوق فيه على الأقل `ceil(n/k)` عنصر. لو كل صندوق فيه أقل من هذا، لن تتسع الصناديق لكل العناصر. المثال يعد أعدادًا بحسب باقيها عند القسمة على 3.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
from collections import Counter

counts = Counter(value % 3 for value in range(10))
print(sorted(counts.items()))
print(max(counts.values()))
```

```exercise
? مع 13 عنصرًا و4 صناديق، ما العدد المضمون في صندوق واحد على الأقل؟
___
= 4
```

```quiz
? لو وزعنا 8 عناصر على 3 صناديق، هل يمكن أن يحتوي كل صندوق على عنصرين على الأكثر؟
- نعم
* لا
- فقط إذا تساوت الصناديق
> الحد المفترض يتسع لستة عناصر فقط.
```

# @lesson combinatorics-recurrence
title: مشروع: عدّ طرق صعود الدرج
summary: مع السماح بخطوة واحدة أو خطوتين، ينتهي أي مسار إلى الدرجة n بخطوة من n−1 أو قفزة من n−2.
---
مع السماح بخطوة واحدة أو خطوتين، ينتهي أي مسار إلى الدرجة n بخطوة من n−1 أو قفزة من n−2. الحالتان منفصلتان، فنجمع العدّين. هناك طريقة واحدة للبقاء عند الصفر، وطريقة واحدة للوصول إلى الدرجة الأولى.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
ways = [1, 1]
for n in range(2, 7):
    ways.append(ways[n - 1] + ways[n - 2])
print(ways)
print(ways[6])
```

```exercise
? كم طريقًا للوصول إلى الدرجة الرابعة؟
___
= 5
```

```quiz
? أي درجتين سبقتا الدرجة السادسة في آخر قفزة ممكنة؟
- 3 و4
- 5 و6
* 4 و5
> آخر حركة تتخطى درجة واحدة أو درجتين.
```
