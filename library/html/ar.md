# @lesson html-intro
title: مقدمة في HTML
summary: ما هي HTML، وكيف يقرأ المتصفح صفحة الويب.
---
**HTML** هي اللغة التي تُكتب بها صفحات الويب. اسمها اختصار لـ *HyperText Markup Language* أي «لغة ترميز النصوص التشعبية».

HTML ليست لغة برمجة؛ هي لغة **ترميز**: تضع حول كل جزء من المحتوى «وسمًا» يخبر المتصفح ما هو: عنوان، فقرة، صورة، رابط…

## أول صفحة

هذه صفحة HTML كاملة. اضغط **تشغيل** لترى النتيجة، ثم غيّر النص وشغّلها مرة أخرى:

```try html
<!DOCTYPE html>
<html>
<head>
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحبًا بالعالم</h1>
  <p>هذه أول فقرة أكتبها بلغة HTML.</p>
</body>
</html>
```

## ماذا يحدث هنا؟

- `<!DOCTYPE html>` يخبر المتصفح أن المستند مكتوب بـ HTML5.
- `<html>` هو العنصر الجذر الذي يحتوي الصفحة كلها.
- `<head>` يحتوي معلومات عن الصفحة لا تظهر داخلها، مثل العنوان في شريط المتصفح.
- `<body>` يحتوي كل ما يراه الزائر.
- `<h1>` عنوان رئيسي، و`<p>` فقرة.

:::info كيف يعمل المتصفح؟
المتصفح لا يعرض الوسوم نفسها؛ يقرأها ليعرف كيف يعرض المحتوى. لذلك ترى «مرحبًا بالعالم» بخط كبير ولا ترى `<h1>`.
:::

```quiz
? ماذا تعني HTML؟
- لغة برمجة للخوادم
* لغة ترميز النصوص التشعبية
- قاعدة بيانات للمواقع
> HTML لغة ترميز تصف محتوى الصفحة.

? محتوى العنصر head يظهر داخل الصفحة للزائر.
= false
> head يحتوي معلومات عن الصفحة مثل العنوان، وما يراه الزائر يكون داخل body.
```

# @lesson html-editors
title: محرر HTML
summary: أين تكتب HTML وكيف تفتح صفحتك في المتصفح.
---
تكفيك أي أداة تكتب نصًا عاديًا لكتابة HTML. لكن المحررات المخصصة للبرمجة تجعل العمل أسهل: تلوّن الكود وتكمل الوسوم وتكشف الأخطاء.

## محررات شائعة

- **Visual Studio Code**: مجاني ويعمل على كل الأنظمة، وهو الأكثر استخدامًا.
- **Notepad++** على ويندوز، أو **TextEdit** على ماك في وضع النص العادي.
- محرر هذه المنصة: كل مثال فيه زر **تشغيل** يعرض النتيجة فورًا دون تثبيت أي شيء.

## خطوات أول ملف على جهازك

1. افتح المحرر وأنشئ ملفًا جديدًا.
2. اكتب صفحة HTML بسيطة.
3. احفظ الملف باسم ينتهي بـ `.html` مثل `index.html`.
4. افتح الملف بالمتصفح (انقر عليه مرتين).

```html
<!DOCTYPE html>
<html>
<body>
  <h1>صفحة على جهازي</h1>
  <p>فتحتها من ملف index.html</p>
</body>
</html>
```

:::tip نصيحة
اجعل اسم الصفحة الرئيسية لموقعك `index.html`؛ الخوادم تفتح هذا الملف تلقائيًا عند زيارة المجلد.
:::

```quiz
? ما الامتداد الصحيح لملف صفحة ويب؟
- .txt
* .html
- .doc
```

# @lesson html-basic
title: أساسيات HTML
summary: الهيكل الأساسي لأي صفحة، والعناوين والفقرات والروابط والصور في مثال واحد.
---
كل صفحة HTML تبدأ بنفس الهيكل، ثم تضيف داخل `<body>` ما تريد عرضه.

## الهيكل الأساسي

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>عنوان الصفحة</title>
</head>
<body>
  ...المحتوى هنا...
</body>
</html>
```

- `lang="ar"` يحدد لغة الصفحة، و`dir="rtl"` يجعل اتجاهها من اليمين لليسار.
- `<meta charset="UTF-8">` يضمن ظهور الحروف العربية بشكل صحيح.

## أمثلة سريعة

العناوين من `<h1>` (الأكبر) إلى `<h6>` (الأصغر). الفقرة `<p>`. الرابط `<a>`. الصورة `<img>`.

```try html
<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<p>هذه فقرة.</p>
<a href="https://www.wikipedia.org">رابط إلى ويكيبيديا</a>
<br>
<img src="https://picsum.photos/200/120" alt="صورة عشوائية" width="200">
```

```exercise html
? أكمل الكود ليصبح النص فقرة
<___>أنا فقرة</p>
= p
! الوسم الذي يغلق في آخر السطر هو نفسه الذي يفتح في أوله.
```

```quiz
? أي وسم يضمن ظهور الحروف العربية بشكل صحيح؟
- <title>
* <meta charset="UTF-8">
- <body>

? السمة dir=rtl تجعل اتجاه الصفحة من اليمين إلى اليسار.
= true
```

# @lesson html-elements
title: عناصر HTML
summary: الوسم الافتتاحي والختامي، والعناصر الفارغة، والعناصر المتداخلة.
---
**العنصر** في HTML هو كل شيء من الوسم الافتتاحي إلى الوسم الختامي:

```html
<p>هذا عنصر فقرة.</p>
```

- `<p>` الوسم الافتتاحي.
- `هذا عنصر فقرة.` المحتوى.
- `</p>` الوسم الختامي، وفيه شرطة مائلة `/`.

## العناصر الفارغة

بعض العناصر ليس لها محتوى ولا وسم ختامي، مثل `<br>` (سطر جديد) و`<img>` (صورة) و`<hr>` (خط فاصل).

```try html
<p>السطر الأول<br>السطر الثاني</p>
<hr>
<p>فقرة بعد الخط الفاصل.</p>
```

## العناصر المتداخلة

يمكن وضع عنصر داخل عنصر آخر. الصفحة كلها عناصر متداخلة: `<body>` داخل `<html>`، و`<p>` داخل `<body>`.

```try html
<body>
  <h1>عنوان</h1>
  <p>فقرة فيها <strong>كلمة عريضة</strong> داخلها.</p>
</body>
```

:::warning لا تنسَ الوسم الختامي
بعض المتصفحات تعرض الصفحة رغم نسيان الوسم الختامي، لكن النتيجة قد تكون غير متوقعة. أغلق كل عنصر تفتحه.
:::

```exercise html
? أكمل الوسم الختامي
<h2>عنوان فرعي<___>
= /h2
```

```quiz
? أي هذه العناصر عنصر فارغ (بلا وسم ختامي)؟
- <p>
* <br>
- <h1>

? الوسم الختامي يحتوي شرطة مائلة / قبل اسم الوسم.
= true
```

# @lesson html-attributes
title: سمات HTML
summary: معلومات إضافية تُكتب داخل الوسم الافتتاحي مثل href و src و alt.
---
**السمات** (attributes) تعطي العنصر معلومات إضافية. تُكتب دائمًا في الوسم الافتتاحي بالشكل `اسم="قيمة"`.

## سمات مهمة

- `href` في الرابط `<a>`: عنوان الصفحة التي يفتحها الرابط.
- `src` في الصورة `<img>`: مسار الصورة.
- `alt` في الصورة: نص بديل يظهر إذا لم تُحمَّل الصورة، وتقرؤه برامج قراءة الشاشة.
- `width` و `height`: عرض وارتفاع الصورة.
- `style`: تنسيق العنصر مباشرة (لون، حجم…).
- `lang` و `dir`: لغة المحتوى واتجاهه.
- `title`: نص يظهر عند مرور الفأرة.

```try html
<a href="https://www.wikipedia.org" title="افتح ويكيبيديا">زر ويكيبيديا</a>
<p style="color: teal;">فقرة بلون مخصص.</p>
<img src="https://picsum.photos/180/100" alt="منظر طبيعي" width="180" height="100">
```

:::tip اكتب القيم بين علامتي تنصيص
`href="page.html"` أوضح وأسلم من `href=page.html`، خاصة إذا كانت القيمة فيها مسافات.
:::

```exercise html
? أكمل السمة التي تحدد مسار الصورة
<img ___="logo.png" alt="الشعار">
= src
```

```quiz
? أين تُكتب السمات؟
* في الوسم الافتتاحي
- في الوسم الختامي
- بعد نهاية العنصر

? ما فائدة السمة alt في الصورة؟
- تحديد عرض الصورة
* نص بديل يصف الصورة
- تحديد مسار الصورة
```

# @lesson html-headings
title: العناوين
summary: من h1 إلى h6، ولماذا ترتيب العناوين مهم.
---
تُعرَّف العناوين بالوسوم من `<h1>` إلى `<h6>`. `<h1>` الأهم والأكبر، و`<h6>` الأقل أهمية.

```try html
<h1>عنوان مستوى 1</h1>
<h2>عنوان مستوى 2</h2>
<h3>عنوان مستوى 3</h3>
<h4>عنوان مستوى 4</h4>
<h5>عنوان مستوى 5</h5>
<h6>عنوان مستوى 6</h6>
```

## لماذا العناوين مهمة؟

- محركات البحث تستخدمها لفهم موضوع الصفحة.
- برامج قراءة الشاشة تتنقل بين العناوين لتساعد المكفوفين.
- الزائر يتصفح العناوين أولًا ليجد ما يريد.

:::tip قاعدة بسيطة
استخدم `<h1>` مرة واحدة لعنوان الصفحة، ثم `<h2>` للأقسام و`<h3>` للأقسام الفرعية. لا تختر العنوان بسبب حجم الخط؛ الحجم يتغير بالتنسيق.
:::

```exercise html
? اكتب أكبر عنوان
<___>عنوان الصفحة</h1>
= h1
```

```quiz
? أي عنوان هو الأهم؟
* <h1>
- <h6>
- <head>

? من الأفضل استخدام <h1> مرة واحدة لعنوان الصفحة.
= true
```

# @lesson html-paragraphs
title: الفقرات
summary: الفقرة، والسطر الجديد، والخط الفاصل، والنص المنسق مسبقًا.
---
الفقرة تبدأ دائمًا في سطر جديد، ويضيف المتصفح مسافة قبلها وبعدها.

```try html
<p>هذه فقرة.</p>
<p>وهذه فقرة أخرى.</p>
```

## المسافات تُختصر

المتصفح يجمع المسافات والأسطر المتتالية في مسافة واحدة. لكسر السطر استخدم `<br>`:

```try html
<p>هذه      الكلمات
مكتوبة على    أكثر من سطر.</p>
<p>السطر الأول<br>السطر الثاني</p>
```

## خط فاصل ونص منسق مسبقًا

- `<hr>` يرسم خطًا أفقيًا يفصل بين موضوعين.
- `<pre>` يعرض النص كما هو بمسافاته وأسطره.

```try html
<p>الموضوع الأول</p>
<hr>
<p>الموضوع الثاني</p>
<pre>
  قصيدة
    بمسافاتها
      كما هي
</pre>
```

```quiz
? كيف تكسر السطر داخل فقرة؟
- <hr>
* <br>
- <pre>

? المتصفح يحافظ على المسافات المتتالية داخل <p> كما هي.
= false
> المسافات المتتالية تُختصر إلى مسافة واحدة، إلا داخل <pre>.
```

# @lesson html-formatting
title: تنسيق النص
summary: عريض، مائل، مهم، مميز، محذوف، مضاف، وأُس وسفلي.
---
توفر HTML عناصر لإعطاء النص معنى خاصًا:

```reference html
<b> | نص عريض (شكل فقط) | <b>عريض</b>
<strong> | نص مهم، يظهر عريضًا | <strong>تحذير</strong>
<i> | نص مائل (شكل فقط) | <i>مائل</i>
<em> | نص مؤكد، يظهر مائلًا | <em>مهم جدًا</em>
<mark> | نص مميز بلون | <mark>ركّز هنا</mark>
<small> | نص أصغر | <small>ملاحظة</small>
<del> | نص محذوف | <del>100</del>
<ins> | نص مضاف | <ins>80</ins>
<sub> | نص سفلي | H<sub>2</sub>O
<sup> | نص علوي (أُس) | x<sup>2</sup>
```

```try html
<p>السعر: <del>100 ريال</del> <ins>80 ريالًا</ins></p>
<p>صيغة الماء H<sub>2</sub>O، ومساحة المربع س<sup>2</sup>.</p>
<p><strong>تنبيه:</strong> احفظ عملك <mark>قبل</mark> الإغلاق.</p>
```

:::info الفرق بين b و strong
الاثنان يظهران عريضين، لكن `<strong>` يعني أن النص **مهم** وتقرؤه برامج قراءة الشاشة بتأكيد. استخدم `<strong>` و`<em>` عندما تقصد المعنى.
:::

```exercise html
? اجعل الرقم 2 أُسًّا
x<___>2</sup>
= sup
```

```quiz

- <small>
```

# @lesson html-comments
title: التعليقات
summary: ملاحظات داخل الكود لا تظهر في الصفحة.
---
التعليق يُكتب بين `<!--` و `-->`. المتصفح يتجاهله، فلا يظهر للزائر، لكنه مفيد لك ولزملائك.

```try html
<!-- هذا تعليق لا يظهر -->
<p>هذه فقرة تظهر.</p>
<!--
<p>فقرة معطلة مؤقتًا</p>
-->
```

## متى تستخدم التعليقات؟

- لشرح جزء معقد من الصفحة.
- لتعطيل جزء مؤقتًا بدل حذفه.
- لتقسيم ملف طويل إلى أقسام واضحة.

:::warning
التعليقات تظهر لأي شخص يفتح «عرض المصدر» في المتصفح. لا تكتب فيها كلمات سر أو معلومات خاصة.
:::

```quiz
? كيف يبدأ التعليق في HTML؟
* <!--
- //
- #

? التعليقات مخفية تمامًا ولا يمكن لأحد رؤيتها.
= false
> لا تظهر في الصفحة، لكنها موجودة في مصدر الصفحة.
```

# @lesson html-links
title: الروابط
summary: الرابط، وفتحه في نافذة جديدة، والروابط الداخلية، وروابط البريد.
---
الروابط هي ما يجعل الويب «شبكة». تُكتب بالعنصر `<a>` والسمة `href`:

```html
<a href="https://www.wikipedia.org">زر ويكيبيديا</a>
```

## فتح الرابط في نافذة جديدة

السمة `target="_blank"` تفتح الرابط في تبويب جديد:

```try html
<a href="https://www.wikipedia.org" target="_blank">ويكيبيديا في تبويب جديد</a>
```

## أنواع العناوين

- **عنوان كامل**: `https://example.com/page.html` لصفحة في موقع آخر.
- **عنوان نسبي**: `about.html` لصفحة في نفس الموقع.
- **رابط لقسم داخل الصفحة**: `#contact` ينقلك إلى العنصر الذي `id="contact"`.
- **بريد إلكتروني**: `mailto:info@example.com` يفتح برنامج البريد.

```try html
<a href="#end">انزل إلى النهاية</a>
<p style="height: 300px;">محتوى طويل…</p>
<h2 id="end">النهاية</h2>
<a href="mailto:info@example.com">راسلنا</a>
```

```exercise html
? أكمل السمة التي تحدد عنوان الرابط

= href
```

```quiz

? الرابط href="#contact" ينقلك إلى العنصر الذي id="contact".
= true
```

# @lesson html-images
title: الصور
summary: إضافة صورة، والنص البديل، والحجم، والصورة كرابط.
---
تُضاف الصورة بالعنصر الفارغ `<img>` وسمتين أساسيتين: `src` لمسار الصورة، و`alt` لوصفها.

```try html
<img src="https://picsum.photos/300/180" alt="منظر طبيعي" width="300" height="180">
```

## لماذا alt مهمة؟

- تظهر بدل الصورة إذا تعذّر تحميلها.
- تقرؤها برامج قراءة الشاشة للمكفوفين.
- تساعد محركات البحث على فهم الصورة.

```try html
<img src="no-such-image.jpg" alt="صورة غير موجودة: يظهر هذا النص بدلها">
```

## الصورة كرابط

ضع `<img>` داخل `<a>`:

```try html
<a href="https://www.wikipedia.org">
  <img src="https://picsum.photos/120/80" alt="اذهب إلى ويكيبيديا">
</a>
```

:::tip حدد العرض والارتفاع
تحديد `width` و`height` يجعل المتصفح يحجز مكان الصورة قبل تحميلها، فلا «تقفز» الصفحة.
:::

```exercise html

<img src="cat.jpg" ___="قطة نائمة">
= alt
```

```quiz

```

# @lesson html-lists
title: القوائم
summary: القائمة النقطية، والقائمة المرقمة، وقائمة التعريفات، والقوائم المتداخلة.
---
## قائمة نقطية

`<ul>` قائمة غير مرتبة، وكل عنصر فيها `<li>`:

```try html
<ul>
  <li>قهوة</li>
  <li>شاي</li>
  <li>حليب</li>
</ul>
```

## قائمة مرقمة

`<ol>` قائمة مرتبة بأرقام:

```try html
<ol>
  <li>افتح المحرر</li>
  <li>اكتب الكود</li>
  <li>احفظ الملف</li>
</ol>
```

## قائمة تعريفات

`<dl>` لمصطلح `<dt>` وتعريفه `<dd>`:

```try html
<dl>
  <dt>HTML</dt>
  <dd>لغة ترميز صفحات الويب</dd>
  <dt>CSS</dt>
  <dd>لغة تنسيق صفحات الويب</dd>
</dl>
```

## قائمة داخل قائمة

```try html
<ul>
  <li>مشروبات
    <ul>
      <li>ساخنة</li>
      <li>باردة</li>
    </ul>
  </li>
  <li>حلويات</li>
</ul>
```

```exercise html

  <li>أولًا</li>
  <li>ثانيًا</li>
</ol>

```


# @lesson html-tables
title: الجداول
summary: الصفوف والخلايا والعناوين، ودمج الخلايا.
---
الجدول `<table>` يتكون من صفوف `<tr>`، وكل صف من خلايا: `<th>` لخلية العنوان و`<td>` لخلية البيانات.

```try html
<table border="1">
  <tr>
    <th>الاسم</th>
    <th>المدينة</th>
  </tr>
  <tr>
    <td>سارة</td>
    <td>الرياض</td>
  </tr>
  <tr>
    <td>أحمد</td>
    <td>القاهرة</td>
  </tr>
</table>
```

## رأس الجدول وجسمه

`<thead>` لصف العناوين و`<tbody>` لبقية الصفوف، و`<caption>` لعنوان الجدول:

```try html
<table border="1">
  <caption>درجات الطلاب</caption>
  <thead>
    <tr><th>الطالب</th><th>الدرجة</th></tr>
  </thead>
  <tbody>
    <tr><td>ليلى</td><td>95</td></tr>
    <tr><td>عمر</td><td>88</td></tr>
  </tbody>
</table>
```

## دمج الخلايا

`colspan` يمد الخلية على أكثر من عمود، و`rowspan` على أكثر من صف:

```try html
<table border="1">
  <tr><th colspan="2">الاسم الكامل</th></tr>
  <tr><td>نور</td><td>محمد</td></tr>
</table>
```

```quiz
? أي وسم يمثل صفًّا في الجدول؟
* <tr>
- <td>
- <th>

? أي سمة تجعل الخلية تمتد على عمودين؟
- rowspan="2"
* colspan="2"
- span="2"
```

# @lesson html-block-inline
title: عناصر الكتلة والعناصر السطرية
summary: الفرق بين div و span، ولماذا تبدأ بعض العناصر في سطر جديد.
---
## عناصر الكتلة (block)

تبدأ دائمًا في سطر جديد وتأخذ العرض كله، مثل `<div>` و`<p>` و`<h1>` و`<ul>` و`<table>`.

## العناصر السطرية (inline)

تبقى داخل السطر ولا تأخذ إلا مساحة محتواها، مثل `<span>` و`<a>` و`<strong>` و`<img>`.

```try html
<div style="background: #e0f2fe;">أنا div: آخذ السطر كله</div>
<div style="background: #fef3c7;">وأنا div آخر في سطر جديد</div>
<p>هذه فقرة فيها <span style="background: #dcfce7;">span</span> داخل السطر.</p>
```

## div و span للتجميع

- `<div>` يجمع عدة عناصر في مجموعة واحدة لتنسيقها أو ترتيبها.
- `<span>` يحيط بجزء صغير من النص لتنسيقه.

```try html
<div style="border: 1px solid #94a3b8; padding: 8px;">
  <h3>بطاقة</h3>
  <p>السعر: <span style="color: crimson;">50 ريالًا</span></p>
</div>
```

```quiz
? أي عنصر يبدأ في سطر جديد ويأخذ العرض كله؟
* <div>
- <span>
- <a>

? العنصر <span> عنصر سطري.
= true
```

# @lesson html-semantic
title: العناصر الدلالية
summary: header و nav و main و article و section و footer.
---
العناصر **الدلالية** تصف معنى محتواها بوضوح، بدل `<div>` عام لكل شيء. هذا يساعد محركات البحث وبرامج قراءة الشاشة ويجعل الكود أسهل في القراءة.

```reference html
<header> | رأس الصفحة أو القسم: الشعار والعنوان | <header>…</header>
<nav> | روابط التنقل الرئيسية | <nav><a href="/">الرئيسية</a></nav>
<main> | المحتوى الرئيسي للصفحة (مرة واحدة) | <main>…</main>
<article> | محتوى مستقل: مقال، منشور، خبر | <article>…</article>
<section> | قسم من المحتوى له عنوان | <section><h2>…</h2></section>
<aside> | محتوى جانبي مرتبط بالموضوع | <aside>…</aside>
<footer> | تذييل الصفحة: حقوق، روابط | <footer>…</footer>
```

```try html
<header>
  <h1>مدونتي</h1>
  <nav><a href="#">الرئيسية</a> | <a href="#">من نحن</a></nav>
</header>
<main>
  <article>
    <h2>أول مقال</h2>
    <p>نص المقال…</p>
  </article>
</main>
<footer>
  <small>جميع الحقوق محفوظة</small>
</footer>
```

```quiz
? أي عنصر مخصص لروابط التنقل؟
- <header>
* <nav>
- <aside>

? يُستخدم <main> مرة واحدة في الصفحة.
= true
```

# @lesson html-forms
title: النماذج
summary: إنشاء نموذج يجمع بيانات الزائر: الحقول والتسميات وزر الإرسال.
---
النموذج `<form>` يجمع بيانات من الزائر ويرسلها إلى الخادم. بداخله حقول الإدخال `<input>` وتسمياتها `<label>`.

```try html
<form>
  <label for="name">الاسم:</label><br>
  <input type="text" id="name" name="name"><br><br>
  <label for="email">البريد:</label><br>
  <input type="email" id="email" name="email"><br><br>
  <input type="submit" value="إرسال">
</form>
```

## أجزاء مهمة

- `<label for="name">` يربط التسمية بالحقل الذي `id="name"`؛ الضغط على التسمية يضع المؤشر في الحقل.
- `name` اسم الحقل عند الإرسال؛ بدونه لا تُرسل قيمته.
- `action` في `<form>` عنوان الصفحة التي تستقبل البيانات، و`method` طريقة الإرسال (`get` أو `post`).

## عناصر أخرى

```try html
<form>
  <label for="msg">رسالتك:</label><br>
  <textarea id="msg" name="msg" rows="3" cols="30"></textarea><br>
  <label for="city">المدينة:</label>
  <select id="city" name="city">
    <option>الرياض</option>
    <option>القاهرة</option>
    <option>دبي</option>
  </select><br><br>
  <button type="submit">أرسل</button>
</form>
```

```exercise html

<label ___="phone">الهاتف</label>
<input type="tel" id="phone" name="phone">
= for
```

```quiz

- تحديد لون الحقل
* إرسال قيمة الحقل باسمه
- عرض نص داخل الحقل

? أي عنصر يُستخدم لنص طويل متعدد الأسطر؟
- <input type="text">

- <select>
```

# @lesson html-input-types
title: أنواع حقول الإدخال
summary: نص، كلمة سر، رقم، تاريخ، اختيار واحد، اختيارات متعددة، والتحقق التلقائي.
---
السمة `type` تغيّر شكل الحقل وسلوكه:

```reference html
text | نص من سطر واحد | <input type="text">
password | كلمة سر تظهر نقاطًا | <input type="password">
email | بريد إلكتروني مع تحقق | <input type="email">
number | رقم مع أسهم | <input type="number" min="1" max="10">
date | منتقي تاريخ | <input type="date">
radio | اختيار واحد من مجموعة | <input type="radio" name="g">
checkbox | اختيارات متعددة | <input type="checkbox">
color | منتقي لون | <input type="color">
range | شريط تمرير | <input type="range">
file | رفع ملف | <input type="file">
```

```try html
<form>
  <input type="password" placeholder="كلمة السر"><br><br>
  <input type="number" min="1" max="5" value="1"><br><br>
  <input type="date"><br><br>
  <label><input type="radio" name="size" value="s"> صغير</label>
  <label><input type="radio" name="size" value="l"> كبير</label><br><br>
  <label><input type="checkbox" name="milk"> حليب</label>
  <label><input type="checkbox" name="sugar"> سكر</label><br><br>
  <input type="color" value="#4338ca">
</form>
```

## التحقق قبل الإرسال

- `required`: الحقل إلزامي.
- `min` و `max`: أقل وأكبر قيمة.
- `maxlength`: أقصى عدد للحروف.
- `pattern`: نمط يجب أن تطابقه القيمة.

```try html
<form>
  <input type="email" required placeholder="بريدك (إلزامي)">
  <input type="submit" value="جرّب الإرسال فارغًا">
</form>
```

:::warning التحقق في المتصفح لا يكفي
يمكن تجاوز تحقق المتصفح بسهولة. يجب أن يتحقق الخادم أيضًا من كل البيانات التي تصله.
:::

```quiz
* radio
- checkbox
- range

? السمة required تجعل الحقل إلزاميًا قبل الإرسال.
= true

? اختر الأنواع التي تعرض منتقيًا خاصًا في المتصفح
* date
* color
- text
```
