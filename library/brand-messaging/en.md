# @lesson brand-messaging-promise
title: Brand promise and learner experience
summary: A brand takes shape through what people expect and what they experience.
---
A brand takes shape through what people expect and what they experience. A useful promise for the Python course is “Start with a practical calculation in your browser.” Check the first lesson to see whether a learner can easily find and run the example.

## Apply it to the Python launch

Write a one-sentence promise and identify one step in the product that verifies it.

```quiz
? What best supports a browser-based start?
* A working example in the first lesson
- A larger logo
- The word “best” alone
> The experience itself shows whether the promise holds.
```

# @lesson brand-messaging-positioning
title: Positioning and differentiation
summary: Specify the audience, need, alternative, and observable difference.
---
Specify the audience, need, alternative, and observable difference. An operations worker might compare an interactive course with a video or a template. An editable sample demonstrates a relevant difference for someone who wants to modify code. A template could be quicker for someone solving a one-off report.

## Apply it to the Python launch

Write a four-line internal positioning brief: who, what they need, what they use today, and which benefit you can demonstrate. Turn the brief into a short audience-facing headline.

```quiz
? Which difference matters to a worker who wants to learn by changing code?
- The course name is longer
* They can edit and run the example
- The message uses more exclamation marks
> The difference supports an action the learner can try.
```

# @lesson brand-messaging-proof
title: Message hierarchy from promise to proof
summary: Start with one benefit, support it with a detail or proof point, then offer a next step.
---
Start with one benefit, support it with a detail or proof point, then offer a next step. For Python, lead with “Try your first calculation in the browser.” Explain that learners can change a number and see the output, then invite them to run the example. Make claims the product can demonstrate.

## Apply it to the Python launch

Draft three lines for the course page: promise, proof, and next action. Replace a broad claim like “learn quickly” with an observable lesson detail.

```quiz
? Which line works as proof below the headline?
- The course is unparalleled
- You will learn everything today
* Change a value and see the output after running it
> The proof describes an action readers can verify.
```

# @lesson brand-messaging-voice
title: Brand voice and tone
summary: Voice is the usual communication style; tone adapts to the situation.
---
Voice is the usual communication style; tone adapts to the situation. Be practical and direct in an ad, and calm and specific when a learner encounters a problem. Keep the benefit and next action consistent in Arabic and English while writing naturally in each language.

## Apply it to the Python launch

Draft one line before signup and another for someone whose example failed. Mark what keeps the voice consistent and explain why the tone changes.

```quiz
? Which line suits a learner facing a run error?
* Run the example again, then check the referenced line if the error returns
- You must have done something wrong
- Sign up for the course immediately
> A calm tone and specific next step help the learner continue.
```

# @lesson brand-messaging-channels
title: Consistency across ad, page, and email
summary: Each channel advances the journey.
---
Each channel advances the journey. The ad draws attention to the benefit, the page explains and demonstrates it, and the welcome email leads to the same example. Copy can adapt to space and context while the promise and the way it is delivered remain aligned.

## Apply it to the Python launch

Make a three-row table for ad, page, and email. Write one line per channel and name the intended next action. Check whether a promise disappears when people arrive at the destination.

```quiz
? If the ad promises a runnable example, where should it lead?
- A general page listing every section
* A page showing the example or a clear route to it
- A second ad with the same copy
> The destination fulfils the promise and reduces effort finding the next step.
```

# @lesson brand-messaging-project
title: Project: build a messaging guide for the Python launch
summary: Deliver a one-page brief with the audience, alternative, promise, proof, and copy for the ad, signup page, and welcome email.
---
Deliver a one-page brief with the audience, alternative, promise, proof, and copy for the ad, signup page, and welcome email. Check comprehension with a neutral question: “What do you expect to happen if you click?” Capture responses and choose one revision for recurring confusion.

## Apply it to the Python launch

In a practice case, if people think they must install Python first, add a short line explaining the browser example. Compare drafts with the same comprehension question. To estimate signup impact, use a separate experiment design.

```quiz
? Which finding gives you a concrete reason to revise the copy?
- One person’s favourite colour was blue
- The word count alone increased
* Several people expected to install Python before running the example
> Recurring confusion identifies information that should be available before the click.
```
