summary: لو كررت تجربة مستقلة n مرة مع نفس احتمال النجاح p، عدد النجاحات يتبع توزيعًا ثنائيًا.
---
لو كررت تجربة مستقلة n مرة مع نفس احتمال النجاح p، عدد النجاحات يتبع توزيعًا ثنائيًا. احتمال k نجاحات بالضبط يساوي `comb(n,k) × p^k × (1−p)^(n−k)`.

# @lesson applied-statistics-confidence
title: فترات الثقة
summary: لعينة مستقلة كبيرة، فترة Wald التقريبية لنسبة المجتمع هي النسبة المشاهدة ± `1.96 × SE` عند مستوى 95%.
---
لعينة مستقلة كبيرة، فترة Wald التقريبية لنسبة المجتمع هي النسبة المشاهدة ± `1.96 × SE` عند مستوى 95%. نجاح المنهج 95% معناه تغطية النسبة الحقيقية في نحو 95% من العينات المتكررة تحت الشروط المناسبة. هذا التقريب قد يضعف مع عينات صغيرة أو نسب قريبة من صفر أو واحد.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات وشوف الفرق.

```try python
from math import sqrt

successes, n = 60, 100
observed = successes / n
margin = 1.96 * sqrt(observed * (1 - observed) / n)
print(round(observed - margin, 3), round(observed + margin, 3))
```

```exercise
? احسب الخطأ المعياري لو p = 0.5 وn = 100. اكتب الناتج عشريًا.
___
= 0.05
```

```quiz
? مع ثبات النسبة وتضاعف حجم العينة أربع مرات، ماذا يحدث لهامش الخطأ؟
- يتضاعف
- يبقى ثابتًا
* ينخفض للنصف
> الهامش يتناسب عكسيًا مع الجذر التربيعي للحجم.
```


# @lesson statistical-models-sampling
title: قانون الأعداد الكبيرة والحد المركزي
summary: لمشاهدات مستقلة بنفس التوزيع، المتوسط يتحرك نحو متوسط المجتمع بمعنى التقارب الاحتمالي تحت شروط القانون.
---
لمشاهدات مستقلة بنفس التوزيع، المتوسط يتحرك نحو متوسط المجتمع بمعنى التقارب الاحتمالي تحت شروط القانون. ومع تباين محدود وغير صفري، يقترب شكل توزيع متوسطات العينات بعد التوحيد المعياري من الطبيعي. المثال يقارن تشتّت متوسطات رميات عملة عند حجمين.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from random import Random
from statistics import mean, pstdev

random = Random(12)
spreads = []
for size in (10, 100):
    averages = [mean(random.randrange(2) for _ in range(size)) for _ in range(500)]
    spreads.append(pstdev(averages))
print(spreads[1] < spreads[0])
```

```exercise
? ما متوسط المجتمع لعملة عادلة مشفّرة بصفر وواحد؟ اكتب عددًا عشريًا.
___
= 0.5
```

# @lesson statistical-models-regression
title: مشروع: الانحدار بأكثر من متغير
summary: استخدم عمودًا لكل ميزة وعمودًا من الواحدات للمقطع.
---
استخدم عمودًا لكل ميزة وعمودًا من الواحدات للمقطع. في المثال المصطنع، المبيعات تزيد وحدتين لكل زيارة إضافية وثلاث وحدات لكل عرض إضافي مع تثبيت المتغير الآخر. المعامل في بيانات حقيقية يصف ارتباطًا مشروطًا، وقد لا يمثّل أثرًا سببيًا.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
import numpy as np

features = np.array([[0, 0], [1, 0], [0, 1], [1, 1]])
sales = np.array([5, 7, 8, 10])
design = np.column_stack((np.ones(len(features)), features))
coefficients = np.linalg.lstsq(design, sales, rcond=None)[0]
print(np.round(coefficients, 3).tolist())
```

```exercise

___
= 12
```

```quiz

- عدد الزيارات في العينة
- القيمة المتوقعة عند مدخلات صفرية
> المقطع 5، ومعامل العروض 3 يصف تغيّر التوقع لكل عرض إضافي.
```

# @lesson stochastic-processes-stationary
title: التوزيع المستقر
summary: التوزيع π مستقر عندما `πP=π`.
---
التوزيع π مستقر عندما `πP=π`. لو احتمال دخول الحالة الثانية من الأولى 0.2، والخروج منها 0.4، فإن الحصة p المستقرة تحقق `p=0.2(1−p)+0.6p`، أي `p=1/3`. الاستقرار يخص التوزيع، والحالة الفردية ما زالت تتغير.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
from fractions import Fraction

enter, leave = Fraction(1, 5), Fraction(2, 5)
p = enter / (enter + leave)
print(p, (1 - p) * enter + p * (1 - leave))
```

```exercise
? إذا كان الدخول والخروج متساويين وموجبين، فما الكتلة المستقرة للحالة الثانية؟ استخدم كسرًا مثل 1/3.
___
= 1/2
```

```quiz
? ماذا يحصل للتوزيع المستقر بعد انتقال واحد؟
- يتحول إلى حالة واحدة
* يبقى كما هو
- يتضاعف
> تعريف الاستقرار هو أن الانتقال يعيد التوزيع نفسه.
```

# @lesson stochastic-processes-walk
title: مشروع: احسب توزيع المشي العشوائي
summary: ابدأ من صفر وكل خطوة مستقلة تتحرك ±1 بالتساوي.
---
ابدأ من صفر وكل خطوة مستقلة تتحرك ±1 بالتساوي. احفظ احتمال كل موقع، ثم انقل نصفه إلى كل جار. بعد ثلاث خطوات، المواقع الممكنة فردية لأن كل خطوة تغيّر الزوجية.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
from collections import defaultdict
from fractions import Fraction

distribution = {0: Fraction(1)}
for _ in range(3):
    next_step = defaultdict(Fraction)
    for position, probability in distribution.items():
        next_step[position - 1] += probability / 2
        next_step[position + 1] += probability / 2
    distribution = next_step
print([(position, str(probability)) for position, probability in sorted(distribution.items())])
```

```exercise
? ما احتمال الموقع 3 بعد ثلاث خطوات؟ استخدم كسرًا مثل 1/2.
___
= 1/8
```

```quiz
? أي موقع لا يمكن الوصول إليه بعد ثلاث خطوات؟
- 1
- −3
* 0
> الزوجية تتغير كل مرة، فبعد ثلاث خطوات يكون الموقع فرديًا.
```
