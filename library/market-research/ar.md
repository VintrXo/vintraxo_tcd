# @lesson market-research-brief
title: سؤال البحث
summary: حدّد القرار قبل جمع البيانات.
---
حدّد القرار قبل جمع البيانات. بنكمّل حالة تسويق دورة Python: القرار هو اختيار أول شريحة تختبر معاها صفحة التسجيل. اسأل عن آخر مهمة حسابية متكررة واجهها الشخص وعن الطريقة اللي استخدمها.

## طبّق على دورة Python

اكتب قرارًا واحدًا وسؤالًا عن تجربة حصلت بالفعل.

```quiz
? أي سؤال يجيب دليلًا عن السلوك؟
* إزاي خلّصت آخر تقرير أسبوعي؟
- أكيد بتحب Python، صح؟
- تحب شعارنا أزرق؟
> السؤال عن حدث سابق يوضّح الطريقة المستخدمة فعليًا.
```

# @lesson market-research-sample
title: طريقة البحث والعينة
summary: البحث الثانوي يبدأ بمعلومات موجودة، مثل وصف العروض المنشورة.
---
البحث الثانوي يبدأ بمعلومات موجودة، مثل وصف العروض المنشورة. البحث الأولي يجمع دليلًا جديدًا، مثل المقابلات. المقابلات تفتح لك باب فهم الأسباب، وتقدير مدى انتشارها يحتاج عينة مناسبة للمجتمع المقصود.

## طبّق على دورة Python

راجع ثلاثة بدائل وحدّد شروط اختيار مشاركين من شريحتين. لو المشاركون كلهم من فريقك، دوّن ده في حدود البحث.

```quiz
? إيه الأنسب عشان تستكشف أسباب التردد في التسجيل؟
- عدّ ألوان الصفحات
* مقابلات مفتوحة
- قراءة عدد الزيارات وحده
> أسئلة المتابعة تكشف أسباب ما يظهرش في عدد الزيارات.
```

اشرح هدف المقابلة وخد موافقة المشارك قبل التسجيل. اسأل عن تجربة حقيقية واستخدم متابعات محايدة. افصل بين اللي قاله الشخص والتفسير اللي إنت استنتجته.

## طبّق على دورة Python

حوّل «كورس عملي هيحل المشكلة، صح؟» إلى سؤال محايد. جرّب: «احكيلي عن آخر مرة حاولت تسرّع إعداد التقرير. عملت إيه بعدها؟».

```quiz
? أي متابعة أقل توجيهًا؟
- أكيد الوقت كان المشكلة؟
- ليه ما اخترتش كورسنا الأفضل؟
* إيه اللي حصل بعدها؟
> المتابعة الأولى لا تقترح سببًا للمشارك.
```

# @lesson market-research-journey
title: البدائل ورحلة قرار العميل
summary: دورة Python تانية منافس مباشر، وقالب جداول يحل المهمة بديل غير مباشر.
---
دورة Python تانية منافس مباشر، وقالب جداول يحل المهمة بديل غير مباشر. ارسم رحلة من ظهور الاحتياج للبحث والمقارنة والتجربة، وسجّل نقطة التوقف أو الرجوع. نفس العميل ممكن يعدّي المراحل بترتيب مختلف حسب الموقف.

## طبّق على دورة Python

قارن فيديو مجاني وقالب جداول ودورة تفاعلية. اكتب لكل بديل سببًا لاختياره وعائقًا، وميّز بين اللي شفته واللي محتاج تختبره.

```quiz
? ما البديل غير المباشر لتعلّم Python هنا؟
* قالب يختصر نفس خطوات التقرير
- دورة Python أخرى
- عنوان صفحة التسجيل
> القالب يلبّي الاحتياج بطريقة مختلفة.
```

# @lesson market-research-evidence
title: تلخيص الملاحظات بدون تضخيم العينة
summary: رمّز الملاحظات بموضوعات زي الوقت والبدائل.
---
رمّز الملاحظات بموضوعات زي الوقت والبدائل. لو مشارك كرّر نفس العائق مرتين، احسبه شخصًا واحدًا عند عدّ المشاركين. اذكر حجم العينة وابحث عن دليل مخالف. وصف عينة مقابلات صغيرة مفيد لاختيار تجربة تالية، والتعميم يحتاج تصميم عينة مناسب.

## طبّق على دورة Python

في المثال الافتراضي، قارن عدد ملاحظات ضيق الوقت بعدد الأشخاص اللي ذكروه. اكتب خلاصة من جملة واحدة تذكر عدد المشاركين.

```try python
notes = [('P1', 'time'), ('P1', 'time'), ('P2', 'template'), ('P3', 'time')]
people = {person for person, theme in notes if theme == 'time'}
print(len(people), sorted(people))
```

```quiz
? كم شخصًا مختلفًا ذكر ضيق الوقت؟
- 3
* 2
- 4
> المشارك P1 ذكره مرتين وP3 مرة، فيتحسبوا شخصين.
```

# @lesson market-research-project
title: مشروع: اختار أول شريحة للاختبار
summary: في بيانات التدريب، عاملان في العمليات وصفوا تقريرًا أسبوعيًا متكررًا، والثالث مكتفٍ بقالب جداول.
---
في بيانات التدريب، عاملان في العمليات وصفوا تقريرًا أسبوعيًا متكررًا، والثالث مكتفٍ بقالب جداول. طالبان وصفا اهتمامًا عامًا ببايثون من غير مهمة حالية. قارن قوة الأدلة ووضوح الاحتياج، واختار تجربة صغيرة تجمع دليلًا إضافيًا.

## طبّق على دورة Python

اكتب مذكرة فيها القرار، وحجم كل شريحة في العينة، ودليل مؤيد، ودليل مخالف، وحدّ للدراسة، وطريقة قياس الاختبار. مثال: نختبر صفحة فيها مثال تقرير مع موظفي العمليات، ونقيس نسبة الزوّار اللي بدأوا المثال. القالب الحالي كفاية لأحد المشاركين، والعينة صغيرة.

```quiz
? أي استنتاج تدعمه البيانات الافتراضية؟
- كل موظفي العمليات هيسجلوا
- الطلبة لا يحتاجون Python مطلقًا
* موظفو العمليات اختيار معقول للاختبار الأول
> الملاحظات تدعم اختيار اختبار، ومش كفاية للتعميم على الشريحتين.
```
