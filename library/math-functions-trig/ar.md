# @lesson functions-rule
title: مدخلات الدالة ومخرجاتها
summary: الدالة تعطي لكل مدخل مسموح مخرجًا واحدًا.
---
الدالة تعطي لكل مدخل مسموح مخرجًا واحدًا. في `f(x) = 2x + 1` يقابل المدخل 3 المخرج 7. ممكن لمدخلين مختلفين أن يشتركا في نفس المخرج.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
def f(x):
    return 2 * x + 1

for x in (-1, 0, 3):
    print(x, f(x))
```

```exercise
? احسب f(4) إذا كانت f(x) = 2x + 1.
___
= 9
```

```quiz
? إذا أعطى المدخل نفسه مخرجين مختلفين، هل العلاقة دالة؟
- نعم
* لا
- فقط إذا كان الناتجان موجبين
> يشترط أن يقابل المدخل الواحد مخرج واحد.
```

# @lesson functions-points
title: الإحداثيات وجدول القيم
summary: النقطة `(x, y)` تتحرك أفقيًا حسب `x` ورأسيًا حسب `y`.
---
النقطة `(x, y)` تتحرك أفقيًا حسب `x` ورأسيًا حسب `y`. نحسب قيمة الدالة لكل مدخل ثم نرسم الزوج الناتج. للقاعدة `y = x + 2` تقع النقطة `(1, 3)` على الرسم.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
for x in range(-2, 3):
    print((x, x + 2))
```

```exercise
? ما الإحداثي الرأسي عند x = −1 على y = x + 2؟
___
= 1
```

```quiz
? أي نقطة تقع على الرسم y = 2x − 1؟
- (3, 2)
- (0, 1)
* (2, 3)
> عند x = 2 نجد y = 2 × 2 − 1 = 3.
```

# @lesson functions-slope
title: الميل والمقطع
summary: في `y = mx + b` يحدد `m` مقدار تغيّر `y` مع زيادة `x` بوحدة، ويحدد `b` قيمة `y` عند `x = 0`.
---
في `y = mx + b` يحدد `m` مقدار تغيّر `y` مع زيادة `x` بوحدة، ويحدد `b` قيمة `y` عند `x = 0`. غيّر الميل في الرسم ولاحظ اتجاه الخط.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
m = -2
b = 3
print(b)
print((m * 2 + b) - (m * 1 + b))
```

```try html

<output id="equation" dir="ltr"></output>
<canvas id="graph" width="360" height="220" style="display:block;max-width:100%;background:#f1f5f9" aria-label="رسم الدالة الخطية"></canvas>
<script>
const slope = document.querySelector('#slope');
const canvas = document.querySelector('#graph');
const ctx = canvas.getContext('2d');

  const m = Number(slope.value);

  ctx.strokeStyle = '#64748b';

  ctx.beginPath();

```

```exercise
? اكتب قيمة المقطع الرأسي في y = 5x − 4.
___
= -4
```

```quiz
? احسب الميل بين النقطتين (1, 2) و(3, 8).
* 3
- 6
- 2
> التغير الرأسي 6 والأفقي 2. الميل هو 6 ÷ 2.
```

# @lesson functions-domain
title: المجال والقيود
summary: المجال هو المدخلات المسموح بها.
---
المجال هو المدخلات المسموح بها. لا نستخدم الصفر في مقام `1/x`. في نموذج يصف عدد الكتب، المدخلات المسموحة أعداد صحيحة غير سالبة لأن العدد يمثل كمية فعلية.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
for x in (-2, -1, 0, 1, 2):
    if x == 0:
        print(x, 'undefined')
    else:
        print(x, 1 / x)
```

```exercise
? ما القيمة الممنوعة في الدالة 1/(x − 3)؟
___
= 3
```

```quiz
? أي مدخل غير مناسب لدالة تحسب تكلفة عدد من الكتب؟
- 0
* 2.5
- 3
> عدد الكتب كمية صحيحة، و2.5 ليس عددًا صحيحًا.
```

# @lesson functions-plans
title: مشروع: قارن خطط اشتراك
summary: الخطة الأولى تكلف 20 ثابتة و5 لكل استخدام، والثانية تكلف 8 لكل استخدام بلا رسوم ثابتة.
---
الخطة الأولى تكلف 20 ثابتة و5 لكل استخدام، والثانية تكلف 8 لكل استخدام بلا رسوم ثابتة. اكتب الدالتين وجرّب أعداد استخدام مختلفة لتحدد أول عدد صحيح تصبح عنده الخطة الأولى أرخص.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر قيمة وجرب من جديد.

```try python
def plan_a(uses):
    return 20 + 5 * uses

def plan_b(uses):
    return 8 * uses

for uses in range(5, 9):
    print(uses, plan_a(uses), plan_b(uses))
```

```exercise
? ما تكلفة الخطة الأولى عند 6 استخدامات؟
___
= 50
```

```quiz
? ما أول عدد صحيح تصبح عنده الخطة الأولى أرخص؟
* 7
- 6
- 8
> عند 6 استخدامات التكلفتان 50 و48. عند 7 تصبحان 55 و56.
```

# @lesson trigonometry-angles
title: الدرجات والراديان
summary: الدورة الكاملة تساوي 360 درجة أو `2π` راديان.
---
الدورة الكاملة تساوي 360 درجة أو `2π` راديان. للتحويل من الدرجات إلى الراديان اضرب في `π/180`. دوال المثلثات في وحدة `math` تتوقع الزاوية بالراديان.

للمراجعة، ارجع إلى درس [[math-geometry-ar/geometry-pythagoras|نظرية فيثاغورس]].

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
from math import degrees, pi, radians

print(round(radians(60) / pi, 6))
print(degrees(pi / 2))
```

```exercise
? كم درجة تساوي π راديان؟
___
= 180
```

```quiz
? ما قياس 90 درجة بالراديان؟
* π/2
- π
- 2π
> نضرب 90 في π/180 فنحصل على π/2.
```

# @lesson trigonometry-ratios
title: الجيب وجيب التمام والظل
summary: بالنسبة لزاوية حادة في مثلث قائم، الجيب هو المقابل على الوتر، وجيب التمام هو المجاور على الوتر، والظل هو المقابل على المجاور.
---
بالنسبة لزاوية حادة في مثلث قائم، الجيب هو المقابل على الوتر، وجيب التمام هو المجاور على الوتر، والظل هو المقابل على المجاور. يتغير تحديد المقابل والمجاور عندما تختار الزاوية الحادة الأخرى.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
opposite = 3
adjacent = 4
hypotenuse = 5
print(opposite / hypotenuse)
print(adjacent / hypotenuse)
print(opposite / adjacent)
```

```exercise
? لو كان المجاور 12 والوتر 13، اكتب جيب التمام ككسر مثل 4/5.
___
= 12/13
```

```quiz
? إذا كان المقابل 5 والمجاور 12، فما ظل الزاوية؟
- 5/13
* 5/12
- 12/5
> الظل يقارن المقابل بالمجاور.
```

# @lesson trigonometry-circle
title: دائرة الوحدة
summary: دائرة الوحدة مركزها الأصل ونصف قطرها واحد.
---
دائرة الوحدة مركزها الأصل ونصف قطرها واحد. نقيس الزاوية الموجبة عكس اتجاه عقارب الساعة من المحور الأفقي الموجب. إحداثي النقطة الأفقي هو جيب التمام، والرأسي هو الجيب، وبكده نقدر نستخدم النسب مع زوايا أكبر من 90 درجة.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
from math import cos, radians, sin

for angle in (0, 90, 180, 270):
    theta = radians(angle)
    print(angle, (round(cos(theta)), round(sin(theta))))
```

```exercise
? ما قيمة جيب زاوية 90 درجة؟
___
= 1
```

```quiz
? أين تقع النقطة عند 180 درجة؟
- (1, 0)
- (0, −1)
* (−1, 0)
> نصف دورة ينقل النقطة إلى الطرف الأيسر من المحور الأفقي.
```

# @lesson trigonometry-period
title: الدورية في الجيب
summary: الجيب يتكرر كل دورة كاملة.
---
الجيب يتكرر كل دورة كاملة. على سبيل المثال، `sin(30°)` يساوي `sin(390°)`. لو استخدمنا `sin(2x)` بدل `sin(x)`، تكفي نصف دورة في `x` لإكمال دورة كاملة في الناتج.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
from math import radians, sin

for angle in (30, 390, 750):
    print(angle, round(sin(radians(angle)), 4))
```

```exercise
? كم درجة تمثل دورة كاملة في sin(x)؟
___
= 360
```

```quiz
? ما طول الدورة بالدرجات للدالة sin(2x)؟
* 180
- 360
- 720
> عندما يزيد x بمقدار 180، يزيد 2x بمقدار 360.
```

# @lesson trigonometry-inverse
title: إيجاد زاوية من نسبة
summary: لو عرفت المقابل والمجاور لزاوية حادة، احسب نسبتهما ثم استخدم الظل العكسي.
---
لو عرفت المقابل والمجاور لزاوية حادة، احسب نسبتهما ثم استخدم الظل العكسي. ترجع `atan` في Python الإجابة بالراديان، ويمكنك تحويلها إلى درجات باستخدام `degrees`.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
from math import atan, degrees

rise = 3
run = 4
print(round(degrees(atan(rise / run)), 2))
```

```exercise
? كم درجة تساوي الزاوية الحادة إذا كان المقابل مساويًا للمجاور؟
___
= 45
```

```quiz
? أي عملية تعيد زاوية من نسبة المقابل إلى المجاور؟
- الجيب
* الظل العكسي
- جيب التمام
> نسبة المقابل إلى المجاور هي الظل، فنستخدم دالته العكسية.
```

# @lesson trigonometry-height
title: مشروع: قدّر ارتفاع برج
summary: على أرض مستوية، تقف على بُعد أفقي 20 مترًا من برج.
---
على أرض مستوية، تقف على بُعد أفقي 20 مترًا من برج. زاوية النظر لأعلى من مستوى عينك إلى قمته 30 درجة، وعينك على ارتفاع 1.6 متر. احسب الارتفاع فوق عينك بالظل، ثم أضف ارتفاع العين. غيّر الزاوية وشوف تأثير خطأ القياس.

## جرّب بنفسك

توقّع الناتج، شغّل المثال، ثم غيّر قيمة وقارن.

```try python
from math import radians, tan

distance = 20
eye_height = 1.6
for angle in (29, 30, 31):
    height = distance * tan(radians(angle)) + eye_height
    print(angle, round(height, 2))
```

```exercise
? لو كانت زاوية الارتفاع 45 درجة والمسافة الأفقية 10 أمتار، فكم مترًا ترتفع القمة عن مستوى عينك؟
___
= 10
```

```quiz
? لماذا نضيف 1.6 متر إلى الناتج؟
- لتصحيح قياس الزاوية
- لتحويل الدرجات إلى راديان
* لتحويل الارتفاع فوق العين إلى ارتفاع فوق الأرض
> حساب الظل يعطي الارتفاع فوق خط النظر الأفقي من العين.
```
