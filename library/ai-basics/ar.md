# @lesson ai-intro
title: ما هو الذكاء الاصطناعي (وما ليس هو)
summary: الذكاء الاصطناعي وتعلّم الآلة والتعلم العميق والذكاء التوليدي، وما يستطيعه كل منها.
---
**الذكاء الاصطناعي (AI)** هو الهدف العام لجعل الحواسيب تؤدي مهام تحتاج عادة إلى تقدير بشري. ومعظم الذكاء الاصطناعي اليوم هو **تعلّم الآلة**: أنظمة تتعلم الأنماط من الأمثلة بدل اتباع قواعد مكتوبة يدويًا.

| المصطلح | المعنى | مثال |
|---|---|---|
| الذكاء الاصطناعي | أي تقنية تجعل الحاسوب يتصرف "بذكاء" | برنامج شطرنج، ومخطط مسارات |
| تعلّم الآلة | تعلّم الأنماط من البيانات | فلتر البريد المزعج، وتوقع المبيعات |
| التعلم العميق | تعلّم آلة بشبكات عصبية كبيرة | التعرف على الوجوه، وتحويل الكلام إلى نص |
| الذكاء التوليدي | نماذج تنشئ نصوصًا أو صورًا أو كودًا جديدًا | ChatGPT و Claude ومولّدات الصور |

```try python
# القواعد مقابل التعلّم: قاعدة مكتوبة يدويًا وحد "متعلَّم" للبريد المزعج
emails = [("WIN a FREE prize now", 1), ("Meeting at 10", 0), ("free coffee in the kitchen", 0),
          ("Claim your FREE reward", 1), ("Invoice attached", 0), ("You WIN, click here", 1)]

def rule(text):                                   # كتب شخص هذه القاعدة
    return int("free" in text.lower())

def caps_score(text):                             # خاصية يستطيع النموذج التعلم منها
    return sum(w.isupper() and len(w) > 1 for w in text.split())

best = max(range(0, 3), key=lambda t: sum((caps_score(x) >= t) == bool(y) for x, y in emails))
print("دقة القاعدة      :", sum(rule(x) == y for x, y in emails), "من", len(emails))
print("الحد المتعلَّم    :", best, "كلمات بأحرف كبيرة ->",
      sum((caps_score(x) >= best) == bool(y) for x, y in emails), "من", len(emails))
```

القاعدة ("تحتوي على free") تخطئ مع الرسائل البريئة، أما الحد المتعلَّم فاختير من الأمثلة. والأنظمة الحقيقية تتعلم من ملايين الأمثلة وإشارات كثيرة معًا.

```quiz

- منظم حرارة يعمل عند 20 درجة
- معادلة SUM في جدول حسابي

? تتعلم أنظمة تعلّم الآلة الأنماط من الأمثلة.
= true
```

# @lesson ai-neuron
title: كيف يتعلم النموذج: خلية عصبية واحدة
summary: الأوزان والتوقعات والأخطاء والانحدار التدريجي، في بضعة أسطر NumPy.
---
**الخلية العصبية** تضرب كل مدخل في **وزن**، وتجمع النتائج، ثم تضغط الناتج إلى رقم بين 0 و 1. و**التدريب** يعني تعديل الأوزان قليلًا في كل مرة لتقليل الخطأ على الأمثلة.

```try python
import numpy as np

# ساعات المذاكرة، ساعات النوم  ->  نجح (1) أو لا (0)
X = np.array([[1, 4], [2, 8], [3, 5], [5, 7], [6, 8], [8, 6], [9, 7], [2, 5]], dtype=float)
y = np.array([0, 0, 0, 1, 1, 1, 1, 0], dtype=float)
X = (X - X.mean(axis=0)) / X.std(axis=0)          # وحّد مقاييس الخصائص

w = np.zeros(2); b = 0.0; lr = 0.5
sigmoid = lambda z: 1 / (1 + np.exp(-z))

for step in range(301):
    p = sigmoid(X @ w + b)                         # توقعات بين 0 و 1
    error = p - y
    w -= lr * X.T @ error / len(y)                 # حرّك الأوزان عكس اتجاه الخطأ
    b -= lr * error.mean()
    if step % 100 == 0:
        loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))
        print(f"step {step:3}  loss {loss:.3f}  weights {w.round(2)}")

print("predictions:", sigmoid(X @ w + b).round(2))
print("accuracy   :", ((sigmoid(X @ w + b) > 0.5) == y).mean())
```

**الخسارة (loss)** تقيس مدى خطأ النموذج، وتنخفض مع استمرار التدريب. والنماذج الكبيرة تفعل هذا بالضبط، لكن بمليارات الأوزان بدل وزنين.

```quiz
- لغة البرمجة

= true
```

# @lesson ai-neural-network
title: الشبكات العصبية
summary: طبقات من الخلايا تتعلم أنماطًا لا تستطيعها خلية واحدة، مثل XOR.
---
الخلية الواحدة لا تستطيع إلا رسم خط مستقيم بين الفئات. ورصّ الخلايا في **طبقات** يتيح للشبكة تعلّم أنماط منحنية ومعقدة. والاختبار الكلاسيكي هو **XOR**: الناتج 1 عندما يكون مدخل واحد بالضبط يساوي 1.

```try python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)
sigmoid = lambda z: 1 / (1 + np.exp(-z))

W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros(4)    # طبقة مخفية: 4 خلايا
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros(1)    # طبقة المخرج: خلية واحدة

for step in range(5001):
    h = sigmoid(X @ W1 + b1)                       # المرور الأمامي
    out = sigmoid(h @ W2 + b2)
    d_out = (out - y) * out * (1 - out)            # المرور العكسي (الانتشار العكسي)
    d_h = d_out @ W2.T * h * (1 - h)
    W2 -= 1.0 * h.T @ d_out;  b2 -= 1.0 * d_out.sum(0)
    W1 -= 1.0 * X.T @ d_h;    b1 -= 1.0 * d_h.sum(0)
    if step % 1000 == 0:
        print(f"step {step:4}  loss {np.mean((out - y) ** 2):.4f}")

for inputs, prediction in zip(X, out.round(2)):
    print(inputs.astype(int), "->", prediction[0])
```

- **المرور الأمامي** يحسب التوقعات طبقة بطبقة.
- **الانتشار العكسي (Backpropagation)** يحسب مساهمة كل وزن في الخطأ، من المخرج رجوعًا إلى المدخل، ليُعدَّل كل وزن في الاتجاه الصحيح.
- التعلم العميق يستخدم طبقات كثيرة وتصاميم خاصة (شبكات التلافيف للصور، والمحوّلات Transformers للغة).

```quiz
? لماذا تستطيع شبكة بطبقة مخفية تعلّم XOR بينما لا تستطيع خلية واحدة؟
* لأن الطبقات تجمع حدودًا بسيطة في حد أكثر تعقيدًا
- لأنها تستخدم أمثلة تدريب أكثر
- لأن XOR لا يحتاج تدريبًا
```

# @lesson ai-language-models
title: كيف تتوقع النماذج اللغوية النص
summary: الرموز (tokens)، وتوقع الكلمة التالية، ونموذج صغير مدرَّب على بضع جمل.
---
**النموذج اللغوي** يقرأ النص كـ **رموز (tokens)**، وهي كلمات أو أجزاء كلمات، ويتعلم توقع الرمز التالي. والنماذج اللغوية الكبيرة (LLMs) مدرَّبة على كميات ضخمة من النصوص، فتلتقط توقعاتها القواعد والمعلومات والأساليب. والنموذج الصغير التالي يعدّ فقط أي كلمة تتبع أي كلمة:

```try python
import random
from collections import Counter, defaultdict

text = """the customer opened a ticket . the agent answered the ticket .
the customer thanked the agent . the agent closed the ticket .
the manager reviewed the ticket . the customer opened a new ticket ."""
tokens = text.split()
print("tokens:", len(tokens), "| vocabulary:", len(set(tokens)))

next_words = defaultdict(Counter)
for a, b in zip(tokens, tokens[1:]):
    next_words[a][b] += 1

print("after 'the':", next_words["the"].most_common(4))

random.seed(8)
word, sentence = "the", ["the"]
for _ in range(9):
    options = next_words[word]
    word = random.choices(list(options), weights=options.values())[0]
    sentence.append(word)
    if word == ".":
        break
print("generated:", " ".join(sentence))
```

الجملة الناتجة **جديدة**: ليست في نص التدريب. وهي أيضًا بلا معنى ("the customer thanked the ticket")، لأن هذا النموذج الصغير يعرف فقط أي كلمة تأتي عادة بعد أي كلمة. أما النماذج الكبيرة فتنظر إلى سياق أطول بكثير (آلاف الرموز) بشبكة عصبية بدل جدول عدّ، لكن المهمة الأساسية واحدة: توقع الرمز التالي.

:::warning الطلاقة ليست صحة
النموذج اللغوي ينتج ما هو **مرجَّح** أن يأتي بعد ذلك، لا ما هو **مؤكد**. ولهذا قد تبدو إجابات الذكاء الاصطناعي واثقة وتكون خاطئة ("الهلوسة").
:::

```quiz
- البحث في الإنترنت مباشرة
```

# @lesson ai-temperature
title: الاحتمالات ودرجة الحرارة
summary: كيف يحوّل النموذج الدرجات إلى اختيارات، ولماذا تختلف الإجابات.
---
لكل رمز تالٍ، ينتج النموذج **درجات** لكل الرموز الممكنة. وتحوّلها دالة **Softmax** إلى احتمالات، ثم **يسحب** النموذج رمزًا منها. وإعداد **درجة الحرارة (temperature)** يتحكم في مدى جرأة هذا الاختيار.

```try python
import numpy as np

words = ["تقرير", "ملخص", "جدول", "قصيدة", "موزة"]
scores = np.array([3.0, 2.6, 1.8, 0.5, -1.0])        # درجات النموذج للكلمة التالية

def softmax(z, temperature):
    z = z / temperature
    e = np.exp(z - z.max())
    return e / e.sum()

rng = np.random.default_rng(1)
for t in [0.2, 1.0, 2.0]:
    p = softmax(scores, t)
    picks = rng.choice(words, size=12, p=p)
    print(f"temperature {t}: " + ", ".join(f"{w} {q:.0%}" for w, q in zip(words, p)))
    print("   12 samples:", " ".join(picks))
```

| درجة الحرارة | السلوك | مناسبة لـ |
|---|---|---|
| منخفضة (0 إلى 0.3) | الرمز الأرجح دائمًا تقريبًا | الحقائق والاستخراج والكود |
| متوسطة (نحو 0.7) | بعض التنوع | الكتابة العامة |
| مرتفعة (أكثر من 1) | مفاجئة وأحيانًا بلا معنى | العصف الذهني |

```quiz

* منخفضة
- مرتفعة
- لا يهم

? مع درجة حرارة أعلى تُختار الكلمات غير المرجحة أكثر.
= true
```

# @lesson ai-embeddings
title: التضمينات والبحث الدلالي
summary: تحويل المعنى إلى متجهات، وتشابه جيب التمام، وإيجاد المستندات المرتبطة.
---
**التضمين (embedding)** قائمة أرقام تمثّل معنى كلمة أو جملة أو مستند. والنصوص المتشابهة في المعنى تحصل على متجهات تشير إلى اتجاهات متقاربة، وهذا يتيح للحاسوب البحث **بالمعنى** لا بالكلمات المتطابقة.

```try python
import numpy as np

# "تضمينات" صغيرة يدوية: [مال، إجازات، تقنية، أشخاص]
docs = {
    "كيف تقدّم مطالبة مصروفات": [0.9, 0.0, 0.1, 0.2],
    "سياسة الإجازة السنوية": [0.1, 0.9, 0.0, 0.3],
    "إعادة تعيين كلمة مرور الحاسوب": [0.0, 0.0, 0.9, 0.1],
    "طلب سلفة على الراتب": [0.8, 0.1, 0.0, 0.3],
    "قواعد العمل من المنزل": [0.0, 0.6, 0.4, 0.3],
}
def cosine(a, b):
    a, b = np.array(a), np.array(b)
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b)))

questions = {
    "دفعت أجرة تاكسي لزيارة عميل، كيف أسترد المبلغ؟": [0.85, 0.05, 0.05, 0.2],
    "كم يوم إجازة لدي؟": [0.1, 0.95, 0.0, 0.2],
}
for q, vec in questions.items():
    ranked = sorted(docs, key=lambda d: cosine(vec, docs[d]), reverse=True)
    print(q)
    for d in ranked[:2]:
        print(f"   {cosine(vec, docs[d]):.2f}  {d}")
```

السؤال الأول لا يشترك تقريبًا في أي كلمة مع "تقديم مطالبة مصروفات"، ومع ذلك يُطابَق بشكل صحيح لأن المتجهات متقاربة. ونماذج التضمين الحقيقية تنتج متجهات بمئات الأبعاد، متعلَّمة من النصوص.

```reference python
embedding | متجه يمثّل المعنى | [0.12, -0.4, ...]
cosine similarity | تقارب متجهين (1 = نفس الاتجاه) | a @ b / (|a| |b|)
البحث الدلالي | ترتيب المستندات حسب تشابهها مع السؤال | sorted(docs, key=similarity)
قاعدة بيانات متجهات | تخزين التضمينات وإيجاد الأقرب بسرعة | pgvector, FAISS
```

```quiz
? ماذا يقارن البحث الدلالي؟
* معنى السؤال والمستندات كمتجهات
- الكلمات المتطابقة فقط
- طول المستندات
```

# @lesson ai-rag
title: التوليد المعزَّز بالاسترجاع (RAG)
summary: الإجابة من مستنداتك: استرجع أولًا، ثم ولّد إجابة بمصادرها.
---
النماذج اللغوية لا تعرف سياسات شركتك، وقد تخترع إجابات. و **RAG** يعالج كثيرًا من ذلك: أولًا **استرجع** أنسب الفقرات من مستنداتك، ثم أعطها للنموذج مع السؤال واطلب منه الإجابة **منها فقط** مع ذكر المصدر.

```try python
import math, re
from collections import Counter

policies = {
    "سياسة الإجازات §2": "يحق للموظف 21 يومًا من الإجازة السنوية، ويمكن ترحيل ما لا يزيد عن 5 أيام غير مستخدمة إلى العام القادم.",
    "المصروفات §4": "تُسترد أجرة التاكسي والوجبات في زيارات العملاء خلال 30 يومًا مع الإيصال.",
    "سياسة التقنية §1": "يجب أن تكون كلمات المرور فريدة، ويُبلَّغ قسم التقنية عن الحاسوب المفقود خلال 24 ساعة.",
    "العمل عن بُعد §3": "يمكن للموظفين العمل من المنزل يومين أسبوعيًا بموافقة المدير.",
}
words = lambda t: re.findall(r"\w+", t.lower())
df = Counter(w for text in policies.values() for w in set(words(text)))

def score(question, text):                         # صلة بسيطة بالكلمات المفتاحية (TF-IDF)
    q, t = Counter(words(question)), Counter(words(text))
    return sum(t[w] * math.log(1 + len(policies) / df[w]) for w in q if w in t)

question = "كم يومًا من الإجازة السنوية يمكن ترحيلها إلى العام القادم؟"
best = sorted(policies, key=lambda k: score(question, policies[k]), reverse=True)[:2]

prompt = "أجب فقط من المصادر التالية. إذا لم تكن الإجابة فيها فقل إنك لا تعرف.\n"
prompt += "اذكر اسم المصدر.\n\n"
for name in best:
    prompt += f"[{name}] {policies[name]}\n"
prompt += f"\nالسؤال: {question}"
print(prompt)
```

هذا التوجيه هو ما يُرسل إلى النموذج اللغوي. ولأن الفقرة الصحيحة مضمَّنة وطُلب من النموذج البقاء داخلها، تكون الإجابة ("حتى 5 أيام، سياسة الإجازات §2") مستندة إلى مصدر وقابلة للتحقق.

:::tip لماذا RAG بدل إعادة التدريب؟
المستندات تتغير كل أسبوع. ومع RAG تحدّث المستندات لا النموذج، ويمكن لكل إجابة أن تشير إلى مصدرها ليتحقق الناس منها.
:::

```quiz
? ما خطوتا RAG؟
* استرجاع الفقرات المناسبة، ثم توليد إجابة منها
- إعادة تدريب النموذج، ثم حذف المستندات
- ترجمة السؤال، ثم التخمين
```

# @lesson ai-prompting
title: كتابة توجيهات جيدة
summary: الدور والسياق والمهمة والشكل والأمثلة، مع توجيهات قبل التحسين وبعده.
---
**التوجيه (prompt)** هو التعليمات التي تعطيها لمساعد الذكاء الاصطناعي، والتوجيهات الواضحة تعطي نتائج أفضل. قائمة مفيدة:

1. **السياق**: من أنت، ولمن الناتج، وما المتوفر لديك.
2. **المهمة**: ما المطلوب بالضبط، مع التفاصيل المهمة.
3. **الشكل**: الطول والبنية والنبرة واللغة.
4. **أمثلة**: مثال أو اثنان لما يبدو عليه الناتج الجيد.
5. **الحدود**: ما يجب تجنبه، و"قل إن لم تكن متأكدًا".

| توجيه ضعيف | توجيه أفضل |
|---|---|
| "اكتب عن سياستنا الجديدة." | "اكتب إعلانًا من 120 كلمة لكل الموظفين عن سياسة العمل عن بُعد الجديدة: يومان أسبوعيًا من 1 مارس، بموافقة المدير. نبرة ودودة، بنسختين عربية وإنجليزية، واختم بجهة التواصل." |
| "أصلح معادلة Excel هذه." | "هذه المعادلة يجب أن تجمع العمود C عندما يكون العمود A هو 'Cairo'، لكنها ترجع 0: `=SUMIF(A:A,Cairo,C:C)`. اشرح الخطأ في جملة واحدة وأعطني المعادلة الصحيحة." |
| "لخّص هذا." | "لخّص محضر الاجتماع التالي في 5 نقاط لمدير لم يحضر. اذكر القرارات والمسؤولين عنها منفصلة. وإذا كان شيء غير واضح فقل ذلك." |

```try python
def build_prompt(task, audience, facts, fmt, extra=""):
    parts = [f"المهمة: {task}", f"الجمهور: {audience}", "المعلومات:"]
    parts += [f"- {f}" for f in facts]
    parts += [f"الشكل: {fmt}", "إذا نقصت أي معلومة فاسأل بدل التخمين."]
    if extra:
        parts.append(extra)
    return "\n".join(parts)

print(build_prompt(
    task="اكتب إعلانًا عن منصة التدريب الجديدة",
    audience="كل الموظفين، ومعظمهم غير تقنيين",
    facts=["تنطلق في 1 مارس", "دورات بالعربية والإنجليزية", "الدخول ببريد العمل"],
```

# @lesson ai-limits
title: الحدود والتحيز والتحقق من مخرجات الذكاء الاصطناعي
summary: الهلوسة، والمعرفة القديمة، والتحيز في البيانات، وكيف تتحقق من الإجابات.
---
أدوات الذكاء الاصطناعي مساعدة قوية، لكن لها نقاط ضعف متوقعة:

- **الهلوسة**: إجابات واثقة لكنها مختلقة، بما فيها مصادر مزيفة.
- **المعرفة القديمة**: النموذج يعرف فقط ما كان في بيانات تدريبه حتى تاريخ معين.
- **التحيز**: النماذج تتعلم من بيانات بشرية، بما فيها من ظلم.
- **لا فهم حقيقي لوضعك**: لا تعرف عقودك أو أنظمتك أو عملاءك ما لم تعطها إياها.

يبيّن المثال كيف تنتج بيانات تدريب متحيزة نموذجًا متحيزًا، حتى دون سوء نية:

```try python
from collections import Counter

# قرارات توظيف سابقة تُستخدم كـ "بيانات تدريب" (القسم، النتيجة)
history = [("sales", "hired")] * 40 + [("sales", "rejected")] * 10 + \
          [("design", "hired")] * 5 + [("design", "rejected")] * 15

rates = {}
for dept in ["sales", "design"]:
    outcomes = Counter(o for d, o in history if d == dept)
    rates[dept] = outcomes["hired"] / sum(outcomes.values())
    print(f"{dept:7} نسبة التوظيف السابقة: {rates[dept]:.0%}")

def naive_model(dept):                       # "يتعلم" من الماضي فقط
    return "recommend" if rates[dept] >= 0.5 else "reject"

for dept in ["sales", "design"]:
    print(f"متقدم جديد لقسم {dept} ->", "يوصي به" if naive_model(dept) == "recommend" else "يرفضه")
print("يكرر النموذج أنماط الماضي. وإذا كان الماضي ظالمًا فالنموذج كذلك.")
```

كيف تتحقق من مخرجات الذكاء الاصطناعي:

1. **تحقّق من الحقائق والأرقام** من مصدر موثوق قبل استخدامها.
2. **اطلب المصادر** وافتحها، وارفض المصادر التي لا تجدها.
3. **اختبر الكود** قبل استخدامه واقرأه.
4. **اترك القرار لإنسان** في كل ما يمس وظائف الناس أو أموالهم أو حقوقهم.

```quiz
? أعطتك أداة ذكاء اصطناعي رقم مادة قانونية لتقتبسها في عقد. ماذا تفعل؟
* أتحقق من المادة في المصدر الرسمي قبل استخدامها
- أستخدمها، فأدوات الذكاء الاصطناعي لا تخطئ في الأرقام
- أسأل الأداة إن كانت متأكدة وأقبل إجابتها

? يمكن لنموذج مدرَّب على بيانات تاريخية متحيزة أن يكرر هذا التحيز.
= true
```

# @lesson ai-at-work
title: استخدام الذكاء الاصطناعي في العمل بمسؤولية
summary: استخدامات جيدة، وقائمة قرار بسيطة، والقواعد التي تتبعها.
---
| استخدامات جيدة | بحذر | تجنّب |
|---|---|---|
| مسودات الرسائل والمستندات | ملخصات التقارير الطويلة (راجعها) | القرارات النهائية بشأن الأشخاص |
| العصف الذهني | ترجمة العقود (تحتاج مراجعة) | لصق بيانات سرية في أدوات غير معتمدة |
| شرح معادلة أو كود | تحليل البيانات (تحقّق من الأرقام) | تقديم مخرجات الذكاء الاصطناعي كحقائق مؤكدة |
| تحويل الملاحظات إلى قائمة مهام | الردود على العملاء (راجعها قبل الإرسال) | تقييمات مزيفة أو انتحال شخصيات |

```try python
def ai_check(task, confidential=False, affects_people=False, tool_approved=True, will_review=True):
    issues = []
    if confidential and not tool_approved:
        issues.append("استخدم الأداة المعتمدة من الشركة أو احذف التفاصيل السرية")
    if affects_people:
        issues.append("يجب أن يتخذ إنسان القرار النهائي ويتحمل مسؤوليته")
    if not will_review:
        issues.append("راجع الناتج وتحقق من معلوماته قبل استخدامه")
    return "يمكن استخدام الذكاء الاصطناعي" if not issues else "انتبه: " + "؛ ".join(issues)

print("مسودة إعلان تدريب                 ->", ai_check("announcement"))
print("تلخيص شكاوى العملاء              ->", ai_check("summary", confidential=True, tool_approved=False))
print("ترتيب المتقدمين للوظائف آليًا      ->", ai_check("ranking", affects_people=True, will_review=False))
```

:::tip كن واضحًا بشأن استخدام الذكاء الاصطناعي
اتبع سياسة شركتك للذكاء الاصطناعي، واذكر أن المستند كُتب بمساعدة الذكاء الاصطناعي إذا كان فريقك يتوقع ذلك، وتبقى مسؤولًا عن كل ما ترسله أو تنشره: الذكاء الاصطناعي يساعد، وأنت توقّع.
:::

```quiz
? من المسؤول عن تقرير أرسلته وكُتبت مسودته بالذكاء الاصطناعي؟
* أنت، الشخص الذي أرسله
- أداة الذكاء الاصطناعي
- لا أحد
```
