# @lesson computational-geometry-orientation
title: اتجاه ثلاث نقاط

محدد المتجهين AB وAC يحدد اتجاه الانعطاف. الموجب عكس عقارب الساعة، والسالب معها، والصفر يعني إن النقاط على خط واحد. مقدار المحدد هو ضعف مساحة المثلث.

# @lesson computational-geometry-segments
title: تقاطع القطع المستقيمة
summary: لو طرفا كل قطعة على جانبين متضادين من خط القطعة الأخرى، يوجد تقاطع داخلي.
---
لو طرفا كل قطعة على جانبين متضادين من خط القطعة الأخرى، يوجد تقاطع داخلي. عند محدد صفر، اختبر هل النقطة بين طرفي القطعة. الاختبار الإضافي يلتقط تلامس الأطراف وتداخل القطع على خط واحد.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
def turn(a, b, c):
    return ((b[0] - a[0]) * (c[1] - a[1])
            - (b[1] - a[1]) * (c[0] - a[0]))

def between(a, b, point):
    return all(min(x, y) <= value <= max(x, y)
               for x, y, value in zip(a, b, point, strict=True))

def intersects(a, b, c, d):
    first, second = turn(a, b, c), turn(a, b, d)
    third, fourth = turn(c, d, a), turn(c, d, b)
    crosses = first * second < 0 and third * fourth < 0
    touching = (
        first == 0 and between(a, b, c)
        or second == 0 and between(a, b, d)
        or third == 0 and between(c, d, a)
        or fourth == 0 and between(c, d, b)
    )
    return crosses or touching

for c, d in [((0, 2), (2, 0)), ((2, 2), (4, 4)), ((3, 3), (4, 4))]:
    print(intersects((0, 0), (2, 2), c, d))
```

```exercise
? كم نقطة مشتركة عند تلامس قطعتين في طرف واحد فقط؟
___
= 1
```

```quiz
? ليه لا يكفي محدد صفر لإثبات التقاطع؟
- القطع لا تتلامس عند الأطراف
* النقطة قد تقع على الخط خارج القطعة
- الصفر يدل على دوران موجب
> القيمة صفر تخص الخط كله، واختبار الحدود يحصر النقطة في القطعة.
```

# @lesson computational-geometry-hull
title: الغلاف المحدّب
summary: الغلاف المحدّب أصغر مجموعة محدّبة تحتوي كل النقاط.
---
الغلاف المحدّب أصغر مجموعة محدّبة تحتوي كل النقاط. نرتب النقاط ونبني سلسلة سفلية وأخرى علوية. نحذف آخر نقطة من السلسلة كلما سبّبت إضافة النقطة الجديدة انعطافًا غير موجب، فنحتفظ برؤوس الغلاف دون النقاط التي تقع بين رأسي حافة.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
def turn(a, b, c):
    return ((b[0] - a[0]) * (c[1] - a[1])
            - (b[1] - a[1]) * (c[0] - a[0]))

def chain(points):
    boundary = []
    for point in points:
        while len(boundary) >= 2 and turn(boundary[-2], boundary[-1], point) <= 0:
            boundary.pop()
        boundary.append(point)
    return boundary

def hull(points):
    ordered = sorted(set(points))
    if len(ordered) <= 1:
        return ordered
    return chain(ordered)[:-1] + chain(reversed(ordered))[:-1]

print(hull([(0, 0), (2, 0), (2, 2), (0, 2), (1, 1), (1, 0)]))
```

```exercise
? كم رأسًا للغلاف في المثال؟
___
= 4
```

```quiz
? ما مصير النقطة (1,0)؟
- تقع خارج الغلاف
- تصبح الرأس الوحيد
* تقع على الحافة بلا تسجيلها كرأس
> النقطة تقع بين ركني الحافة السفلى.
```

# @lesson computational-geometry-area
title: مشروع مساحة مضلع
summary: رتّب رؤوس مضلع بسيط حول حدّه.
---
رتّب رؤوس مضلع بسيط حول حدّه. اجمع `xᵢyᵢ₊₁−yᵢxᵢ₊₁` لكل ضلع مع وصل الأخير بالأول. المساحة هي نصف القيمة المطلقة، وعكس ترتيب الرؤوس يعكس إشارة المجموع.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
from fractions import Fraction

def double_signed_area(vertices):
    following = vertices[1:] + vertices[:1]
    return sum(x * ny - y * nx for (x, y), (nx, ny) in zip(vertices, following, strict=True))

polygon = [(1, 1), (4, 1), (4, 3), (1, 3)]
```
