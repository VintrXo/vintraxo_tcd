# @lesson excel-intro
title: مقدمة Excel
summary: المصنفات والأوراق والخلايا والنطاقات، وإدخال البيانات بشكل منظم.
---
ينظّم **Excel** (والأدوات المشابهة مثل Google Sheets و LibreOffice Calc) البيانات في شبكة. الملف **مصنف (workbook)** يحتوي على **أوراق (sheets)**، وكل ورقة مكوّنة من **خلايا** تُسمّى بحرف العمود ورقم الصف، مثل `B3`.

| | A | B | C |
|---|---|---|---|
| **1** | المنتج | السعر | الكمية |
| **2** | شاي | 12.5 | 40 |
| **3** | قهوة | 20 | 25 |
| **4** | كعك | 35 | 10 |

- `B3` هي الخلية في العمود B والصف 3، وفيها `20`.
- `A2:C4` **نطاق**: كل الخلايا من A2 إلى C4.
- `B:B` هو العمود B كله، و `2:2` هو الصف 2 كله.

:::tip نظّم البيانات
صف عناوين واحد، ونوع قيمة واحد في كل عمود (الأرقام تبقى أرقامًا والتواريخ تبقى تواريخ)، ولا صفوف فارغة في المنتصف، ولا خلايا مدمجة داخل البيانات. البيانات المنظمة تسهّل كل معادلة وتصفية وجدول محوري.
:::

```exercise excel
? اكتب النطاق الذي يغطي أسعار المنتجات الثلاثة في الجدول
=SUM(___)
= B2:B4
```

```quiz
? إلامَ يشير اسم الخلية C2؟
* العمود C والصف 2
- الصف C والعمود 2
- الورقة الثانية

? النطاق A2:C4 يشمل كل الخلايا بين A2 و C4.
= true
```

# @lesson excel-formulas
title: المعادلات والعمليات
summary: البدء بعلامة =، والحساب، وترتيب العمليات، ودمج النصوص.
---
كل معادلة تبدأ بـ `=`، ويمكن أن تحتوي على أرقام ومراجع خلايا وعمليات، وتُعاد حسابها عند تغير الخلايا.

| | A | B | C | D |
|---|---|---|---|---|
| **1** | المنتج | السعر | الكمية | الإجمالي |
| **2** | شاي | 12.5 | 40 | `=B2*C2` ← **500** |
| **3** | قهوة | 20 | 25 | `=B3*C3` ← **500** |

| المعادلة | الناتج | السبب |
|---|---|---|
| `=2+3*4` | 14 | الضرب قبل الجمع |
| `=(2+3)*4` | 20 | الأقواس أولًا |
| `=10/4` | 2.5 | القسمة |
| `=2^3` | 8 | الأس |
| `=A2&" × "&C2` | شاي × 40 | `&` تدمج النصوص |
| `=B2*(1+14%)` | 14.25 | السعر مع ضريبة 14% |

:::tip اسحب للأسفل بدل إعادة الكتابة
اكتب المعادلة مرة واحدة في `D2`، ثم اسحب المربع الصغير في زاوية الخلية للأسفل (أو انقر عليه مرتين). ينسخ Excel المعادلة ويعدّل أرقام الصفوف: `=B3*C3` و `=B4*C4`...
:::

```exercise excel

=B4___C4
= *
```


# @lesson excel-references
title: المراجع النسبية والمطلقة
summary: ماذا يحدث عند نسخ المعادلات، ومتى نستخدم علامة $.
---
عندما تنسخ معادلة، يحرّك Excel مراجعها بنفس المسافة، وهذا **مرجع نسبي** (`B2`). وأحيانًا يجب أن تبقى خلية ثابتة مثل نسبة الضريبة، وهذا **مرجع مطلق** (`$F$1`).

| | A | B | C | ... | F |
|---|---|---|---|---|---|
| **1** | المنتج | السعر | مع الضريبة | | **0.14** (نسبة الضريبة) |
| **2** | شاي | 12.5 | `=B2*(1+$F$1)` ← 14.25 | | |
| **3** | قهوة | 20 | `=B3*(1+$F$1)` ← 22.8 | | |

لو كانت `C2` هي `=B2*(1+F1)` فإن نسخها للأسفل يعطي `=B3*(1+F2)`، والخلية `F2` فارغة فتختفي الضريبة.

| المرجع | عند النسخ للأسفل | عند النسخ لليمين |
|---|---|---|
| `B2` | الصف يتغير | العمود يتغير |
| `$B$2` | ثابت | ثابت |
| `B$2` | الصف ثابت | العمود يتغير |
| `$B2` | الصف يتغير | العمود ثابت |

:::tip مفتاح F4
انقر على مرجع داخل شريط المعادلة واضغط **F4** (على Mac اضغط Cmd+T) للتنقل بين `B2` و `$B$2` و `B$2` و `$B2`.
:::

```exercise excel
? اجعل مرجع نسبة الضريبة في F1 ثابتًا عند نسخ المعادلة
=B2*(1+___)
= $F$1
```

```quiz

* $F$1
- F1
- F$1
```

# @lesson excel-functions
title: الدوال الأساسية
summary: SUM و AVERAGE و MIN و MAX و COUNT و COUNTA و ROUND وشريط الحالة.
---
**الدوال** معادلات جاهزة: اسم ثم معاملات بين أقواس.

| | A | B |
|---|---|---|
| **1** | الموظف | المبيعات |
| **2** | سارة | 1200 |
| **3** | عمر | 950 |
| **4** | لينا | (فارغة) |
| **5** | كريم | 1400 |

| المعادلة | الناتج | المعنى |
|---|---|---|
| `=SUM(B2:B5)` | 3550 | المجموع |
| `=AVERAGE(B2:B5)` | 1183.33 | متوسط الأرقام (تُتجاهل الخلايا الفارغة) |
| `=MIN(B2:B5)` / `=MAX(B2:B5)` | 950 / 1400 | الأصغر / الأكبر |
| `=COUNT(B2:B5)` | 3 | عدد **الأرقام** |
| `=COUNTA(A2:A5)` | 4 | عدد الخلايا **غير الفارغة** |
| `=COUNTBLANK(B2:B5)` | 1 | الخلايا الفارغة |
| `=ROUND(AVERAGE(B2:B5), 0)` | 1183 | التقريب بلا كسور |

:::tip إجابات سريعة بلا معادلات
حدّد نطاقًا وانظر إلى **شريط الحالة** أسفل النافذة: يعرض Excel مجموع التحديد ومتوسطه وعدده.
:::

:::info فاصلة أم فاصلة منقوطة؟
في بعض الإعدادات الإقليمية يفصل Excel بين المعاملات بـ `;` بدل `,`، مثل `=ROUND(B2;0)`. وأسماء الدوال تبقى بالإنجليزية في النسخة العربية من Excel.
:::

```exercise excel
= COUNT
```


# @lesson excel-logic
title: القرارات بـ IF و AND و OR
summary: IF والشروط المتداخلة و IFS و AND و OR، والتعامل مع الأخطاء بـ IFERROR.
---
| | A | B | C |
|---|---|---|---|
| **1** | الموظف | الدرجة | النتيجة |
| **2** | سارة | 91 | `=IF(B2>=60,"ناجح","راسب")` ← ناجح |
| **3** | عمر | 54 | ← راسب |
| **4** | لينا | 75 | ← ناجح |

| المعادلة | الناتج للدرجة 91 | المعنى |
|---|---|---|
| `=IF(B2>=60,"ناجح","راسب")` | ناجح | شرط واحد |
| `=IFS(B2>=90,"ممتاز",B2>=75,"جيد جدًا",B2>=60,"مقبول",TRUE,"راسب")` | ممتاز | عدة شروط بالترتيب |
| `=IF(AND(B2>=60,C2="نعم"),"معتمد","ليس بعد")` | حسب C2 | يجب أن يتحقق الشرطان |
| `=IF(OR(B2>=90,D2="مدير"),"مسار سريع","عادي")` | مسار سريع | يكفي تحقق شرط واحد |
| `=IFERROR(B2/E2,0)` | 0 إذا كانت E2 فارغة | استبدال الخطأ بقيمة |

- المقارنات: `=` و `<>` (لا يساوي) و `>` و `<` و `>=` و `<=`.
- النصوص داخل المعادلات توضع بين علامتي تنصيص مزدوجتين: `"ناجح"`.

:::warning لا تخفِ كل الأخطاء
`IFERROR` مفيدة للحالات المتوقعة مثل القسمة على خلية فارغة. لكن تغليف كل شيء بها قد يخفي أخطاء حقيقية، مثل نطاق خاطئ.
:::

```exercise excel

=___(B2>1000,"مرتفع","عادي")
= IF
```

```quiz
- AND

```

# @lesson excel-conditional-sums
title: المجاميع والأعداد المشروطة
summary: SUMIF و SUMIFS و COUNTIF و COUNTIFS و AVERAGEIF على جدول مبيعات.
---
| | A | B | C | D |
|---|---|---|---|---|
| **1** | التاريخ | الفرع | المنتج | المبلغ |
| **2** | 2026-01-03 | القاهرة | لابتوب | 25000 |
| **3** | 2026-01-03 | الجيزة | ماوس | 450 |
| **4** | 2026-01-10 | القاهرة | شاشة | 6000 |
| **5** | 2026-02-02 | الإسكندرية | لابتوب | 24000 |
| **6** | 2026-02-15 | القاهرة | ماوس | 500 |

| المعادلة | الناتج | السؤال |
|---|---|---|
| `=SUMIF(B2:B6,"القاهرة",D2:D6)` | 31500 | إجمالي مبيعات القاهرة |
| `=COUNTIF(C2:C6,"لابتوب")` | 2 | عدد مبيعات اللابتوب |
| `=SUMIFS(D2:D6,B2:B6,"القاهرة",D2:D6,">1000")` | 31000 | مبيعات القاهرة الأكبر من 1000 |
| `=COUNTIFS(B2:B6,"القاهرة",A2:A6,">="&DATE(2026,2,1))` | 1 | مبيعات القاهرة من فبراير |
| `=AVERAGEIF(C2:C6,"ماوس",D2:D6)` | 475 | متوسط بيع الماوس |

- `SUMIF(النطاق_المفحوص، الشرط، نطاق_الجمع)` فيها شرط **واحد**.
- `SUMIFS(نطاق_الجمع، نطاق1، شرط1، نطاق2، شرط2، ...)` فيها شروط **كثيرة**، ونطاق الجمع يأتي **أولًا**.
- الشروط التي فيها عمليات توضع بين علامتي تنصيص: `">1000"`. ولاستخدام قيمة خلية ادمجها: `">="&F1`.

# @lesson excel-lookup
title: البحث عن القيم
summary: XLOOKUP و VLOOKUP و INDEX/MATCH لجلب بيانات من جدول آخر.
---
**البحث (lookup)** يجد قيمة في جدول ويرجع معلومة مرتبطة بها، مثل سعر رمز منتج.

**ورقة المنتجات**

| | A | B | C |
|---|---|---|---|
| **1** | الرمز | المنتج | السعر |
| **2** | P01 | لابتوب | 25000 |
| **3** | P02 | شاشة | 6000 |
| **4** | P03 | ماوس | 450 |

| المعادلة | الناتج | ملاحظات |
|---|---|---|
| `=XLOOKUP("P02",A2:A4,C2:C4)` | 6000 | الطريقة الحديثة: عمود البحث ثم عمود النتيجة |
| `=XLOOKUP("P09",A2:A4,C2:C4,"غير موجود")` | غير موجود | قيمة مدمجة عند عدم الوجود |
| `=VLOOKUP("P02",A2:C4,3,FALSE)` | 6000 | الطريقة الأقدم: رقم العمود 3، و `FALSE` = تطابق تام |
| `=INDEX(C2:C4,MATCH("P02",A2:A4,0))` | 6000 | تعمل في كل الإصدارات وفي أي اتجاه |

:::warning استخدم التطابق التام دائمًا
في `VLOOKUP` ترك المعامل الأخير أو كتابة `TRUE` يعني تطابقًا **تقريبيًا**، فيرجع أسعارًا خاطئة بصمت مع الرموز غير المرتبة. اكتب دائمًا `FALSE` (أو استخدم `XLOOKUP` التي تطابق تمامًا افتراضيًا).
:::

:::tip XLOOKUP إن توفرت لديك
`XLOOKUP` متاحة في Microsoft 365 و Excel 2021 وما بعده، وفي Google Sheets. تستطيع البحث يسارًا وإرجاع عدة أعمدة، ولا تتعطل عند إدراج أعمدة.
:::

```exercise excel
? أرجع سعر الرمز P03 من جدول المنتجات
=___("P03",A2:A4,C2:C4)
= XLOOKUP
```

```quiz
? ماذا تعني FALSE كمعامل أخير في VLOOKUP؟
* تطابق تام فقط
- البحث من الأسفل
- إرجاع العمود الأول
```

# @lesson excel-text-dates
title: دوال النصوص والتواريخ
summary: تنظيف النصوص ودمجها، والحساب بالتواريخ.
---
| المعادلة | الناتج | الاستخدام |
|---|---|---|
| `=TRIM("  سارة   علي ")` | سارة علي | حذف المسافات الزائدة |
| `=PROPER("sara ali")` / `=UPPER(A2)` | Sara Ali / SARA ALI | تغيير حالة الأحرف الإنجليزية |
| `=LEFT("INV-2026-0042",3)` | INV | الأحرف الأولى |
| `=RIGHT("INV-2026-0042",4)` | 0042 | الأحرف الأخيرة |
| `=TEXTJOIN("، ",TRUE,A2:A4)` | شاي، قهوة، كعك | دمج نطاق بفاصل |
| `=TEXT(1234.5,"#,##0.00")` | 1,234.50 | تنسيق رقم كنص |
| `=TODAY()` | تاريخ اليوم | يتغير كل يوم |
| `=DATE(2026,3,1)` | 2026-03-01 | بناء تاريخ |
| `=B2-A2` | 45 | الأيام بين تاريخين |
| `=NETWORKDAYS(A2,B2)` | أيام العمل | يستبعد عطلات نهاية الأسبوع |
| `=EDATE(A2,3)` | بعد 3 أشهر | تواريخ انتهاء العقود |
| `=TEXT(A2,"mmmm")` | اسم الشهر | التجميع حسب الشهر |

يخزّن Excel التاريخ كعدد أيام، ولهذا يمكنك طرح التواريخ. وإذا رفض "تاريخ" الحساب فهو غالبًا نص: حوّله من البيانات ← تحويل النص إلى أعمدة، أو بـ `DATEVALUE`.
:::

:::tip عطلة نهاية الأسبوع الجمعة والسبت؟
`NETWORKDAYS.INTL(A2,B2,7)` تعتبر الجمعة والسبت عطلة نهاية الأسبوع، كما في مصر ومعظم دول الخليج.
:::

# @lesson excel-tables-filters
title: الجداول والترتيب والتصفية والتحقق
summary: جداول Excel، والترتيب والتصفية، والقوائم المنسدلة للتحقق، والتنسيق الشرطي.
---
تحويل النطاق إلى **جدول Excel** (Ctrl+T أو إدراج ← جدول) يعطيك أزرار التصفية والصفوف الملوّنة بالتناوب، ومعادلات تتسع تلقائيًا مع الصفوف الجديدة.

| الميزة | الطريقة | الفائدة |
|---|---|---|
| الجدول | Ctrl+T | تُضمَّن الصفوف الجديدة في المعادلات والرسوم والجداول المحورية |
| المراجع المنظمة | `=SUM(Sales[Amount])` | معادلات مقروءة بأسماء الأعمدة |
| الترتيب | البيانات ← فرز | الترتيب حسب عمود أو أكثر |
| التصفية | البيانات ← تصفية | إظهار الصفوف المطابقة فقط |
| التحقق من البيانات | البيانات ← التحقق من صحة البيانات ← قائمة | قوائم منسدلة بلا أخطاء كتابة |
| التنسيق الشرطي | الصفحة الرئيسية ← تنسيق شرطي | إبراز القيم والمكرر وأعلى 10 وأشرطة البيانات |
| تجميد الأجزاء | عرض ← تجميد الأجزاء | إبقاء العناوين ظاهرة أثناء التمرير |
| إزالة التكرارات | البيانات ← إزالة التكرارات | تنظيف الصفوف المكررة |

:::tip التحقق يمنع فوضى البيانات
إذا كتب الناس "القاهره" و"القاهرة" و"القاهرة " في نفس العمود، فستعاملها SUMIF كقيم مختلفة. والقائمة المنسدلة (التحقق من البيانات) تُبقي القيم موحدة من البداية.
:::

# @lesson excel-pivot
title: الجداول المحورية
summary: تلخيص آلاف الصفوف حسب الفئة والشهر ببضع نقرات.
---
**الجدول المحوري (PivotTable)** يلخّص جدولًا دون معادلات: تسحب الحقول إلى **الصفوف** و**الأعمدة** و**القيم** و**عوامل التصفية**.

بدءًا من جدول المبيعات في درس المجاميع المشروطة:

1. انقر داخل البيانات واختر **إدراج ← جدول محوري**.
2. اسحب **الفرع** إلى الصفوف، و**المنتج** إلى الأعمدة، و**المبلغ** إلى القيم (يصبح "مجموع المبلغ").
3. اسحب **التاريخ** إلى الصفوف تحت الفرع وجمّعه حسب **الأشهر** (زر الفأرة الأيمن ← تجميع).

| مجموع المبلغ | لابتوب | شاشة | ماوس | الإجمالي |
|---|---|---|---|---|
| الإسكندرية | 24000 | | | 24000 |
| القاهرة | 25000 | 6000 | 500 | 31500 |
| الجيزة | | | 450 | 450 |
| **الإجمالي** | **49000** | **6000** | **950** | **55950** |

- غيّر "المجموع" إلى **العدد** أو **المتوسط** أو **النسبة من الإجمالي** من إعدادات حقل القيمة.
- أضف **مقسّمات طرق العرض (Slicers)** لتصفية بالنقر.
- عند تغير البيانات الأصلية اضغط **تحديث** (البيانات ← تحديث الكل).

:::tip ابدأ من جدول Excel

# @lesson excel-charts
title: الرسوم البيانية ولوحة بسيطة
summary: اختيار الرسم المناسب، وبناؤه من جدول أو جدول محوري، وإبقاؤه واضحًا.
---
| السؤال | الرسم |
|---|---|
| كيف تتغير قيمة مع الزمن؟ | رسم خطي |
| أي فئة هي الأكبر؟ | أعمدة رأسية أو أفقية (مرتبة) |
| ما حصة كل جزء (2 إلى 4 أجزاء)؟ | دائري أو حلقي |
| هل توجد علاقة بين رقمين؟ | رسم تشتت |
| كيف تتوزع القيم؟ | مدرج تكراري أو رسم صندوقي |

الخطوات: حدّد البيانات (أو انقر على جدول محوري) ← **إدراج** ← اختر الرسم ← أضف عنوانًا واضحًا ← احذف ما لا يفيد (خطوط الشبكة، والتأثيرات ثلاثية الأبعاد، ومفتاح الرسم لسلسلة واحدة).

**لوحة بسيطة**: ضع جدولًا محوريًا و**رسمًا محوريًا (PivotChart)** في ورقة منفصلة، وأضف مقسّمًا أو اثنين مرتبطين بكل الجداول المحورية (اتصالات التقرير)، وبعض الأرقام الأساسية في الأعلى بمعادلات مثل `=SUM(Sales[Amount])`.

:::tip عناوين تقول النتيجة
عنوان "القاهرة تبيع 31,500 جنيه، أي 56% من الإجمالي" يقول للقارئ أكثر من "المبيعات حسب الفرع".
:::

```quiz
? أي رسم يعرض الإيرادات الشهرية على مدار سنة بأفضل شكل؟
* رسم خطي
- رسم دائري
- رسم تشتت

? ترتيب الأعمدة من الأكبر إلى الأصغر يجعل رسم الأعمدة أسهل في القراءة.
= true
```

# @lesson excel-reference
title: مرجع Excel السريع
summary: أكثر المعادلات والاختصارات والعادات استخدامًا في صفحة واحدة.
---
| المعادلة | الاستخدام |
|---|---|
| `=SUM / AVERAGE / MIN / MAX / COUNT / COUNTA` | التلخيص الأساسي |
| `=ROUND(x,2)` | التقريب |
| `=IF / IFS / AND / OR / IFERROR` | القرارات |
| `=SUMIFS / COUNTIFS / AVERAGEIFS` | المجاميع بشروط |
| `=XLOOKUP / INDEX+MATCH / VLOOKUP(…,FALSE)` | البحث عن القيم |
| `=TRIM / PROPER / LEFT / RIGHT / TEXTJOIN / TEXT` | النصوص |
| `=TODAY / DATE / EDATE / NETWORKDAYS.INTL` | التواريخ |
| `$A$1` / F4 | المراجع المطلقة |

| الاختصار | الإجراء |
|---|---|
| Ctrl+T | إنشاء جدول |
| Ctrl+Shift+L | تشغيل التصفية وإيقافها |
| Ctrl+سهم | القفز إلى حافة البيانات |
| Ctrl+Shift+سهم | التحديد حتى الحافة |
| Alt+= | الجمع التلقائي |
| Ctrl+; | تاريخ اليوم |
| F2 | تحرير الخلية |
| F4 | تبديل $ في المرجع |

:::tip الخطوة التالية
خذ تقريرًا تحدّثه يدويًا كل شهر، وحوّل بياناته إلى جدول، واستبدل المجاميع اليدوية بـ SUMIFS أو جدول محوري، وأضف رسمًا بعنوان يقول النتيجة. ثم استكشف Power Query (البيانات ← الحصول على البيانات) لاستيراد البيانات وتنظيفها تلقائيًا. وللتحليلات الأكبر تابع دورات SQL و pandas و Matplotlib في هذه المكتبة.
:::
