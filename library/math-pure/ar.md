# @lesson abstract-algebra-groups
title: مسلّمات الزمرة
summary: الزمرة مجموعة مع عملية مغلقة وتجميعية، لها عنصر محايد ومعكوس لكل عنصر.
---
الزمرة مجموعة مع عملية مغلقة وتجميعية، لها عنصر محايد ومعكوس لكل عنصر. الأعداد `0` إلى `5` مع الجمع بترديد 6 زمرة، والمحايد صفر. التجميعية تأتي من الجمع العادي، وأخذ الباقي لا يغيّر النتيجة بترديد 6.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
modulus = 6
for value in range(modulus):
    inverse = (-value) % modulus
    print(value, inverse, (value + inverse) % modulus)
```

```exercise

___
= 5
```


# @lesson abstract-algebra-cyclic
title: الزمر الدورية ورتبة العنصر
summary: رتبة العنصر في زمرة جمعيّة هي أصغر عدد موجب من تكرارات جمعه تعيدنا للصفر.
---
رتبة العنصر في زمرة جمعيّة هي أصغر عدد موجب من تكرارات جمعه تعيدنا للصفر. العنصر يولّد كل البواقي لو مرّ عليها كلها قبل الرجوع. بترديد 6، العنصر 2 يولّد المجموعة `{0,2,4}`، أما 5 فيولّد الزمرة كلها.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from math import gcd

modulus = 6
for value in (0, 2, 5):
    order = modulus // gcd(value, modulus)
    multiples = [(i * value) % modulus for i in range(order)]
    print(value, order, multiples)
```

```exercise
? كم رتبة 3 بالجمع بترديد 6؟
___
= 2
```

```quiz
? أي عنصر في الخيارات يولّد كل البواقي بترديد 6؟
- 2
* 5
- 3
> القاسم المشترك الأكبر لـ5 و6 يساوي 1، فرتبة 5 تساوي 6.
```

# @lesson abstract-algebra-homomorphism
title: التماثلات الحافظة للعملية والنواة
summary: التماثل الحافظ للعملية يحقق `f(a+b)=f(a)+f(b)` في الزمر الجمعية.
---
التماثل الحافظ للعملية يحقق `f(a+b)=f(a)+f(b)` في الزمر الجمعية. إرسال باقي القسمة بترديد 6 إلى باقيه بترديد 2 يحفظ الجمع لأن 2 يقسم 6. النواة هي عناصر المصدر التي تذهب إلى المحايد، وهنا هي `{0,2,4}`.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
def parity(value):
    return value % 2

kernel = [x for x in range(6) if parity(x) == 0]
preserves = all(parity((a + b) % 6) == (parity(a) + parity(b)) % 2
                for a in range(6) for b in range(6))
print(kernel)
print(preserves)
```

```exercise
? كم عنصرًا في نواة تحويل الباقي بترديد 6 إلى الباقي بترديد 2؟
___
= 3
```

```quiz
? أي عنصر صورته هي المحايد؟
* 4
- 1
- 5
> المحايد في الهدف صفر، و4 زوجي.
```

# @lesson real-analysis-continuity
title: الاستمرارية بتعريف إبسيلون ودلتا
summary: نقول إن f مستمرة عند a إذا أمكن جعل `|f(x)−f(a)|<ε` باختيار `|x−a|<δ`.
---
نقول إن f مستمرة عند a إذا أمكن جعل `|f(x)−f(a)|<ε` باختيار `|x−a|<δ`. للدالة `f(x)=3x+2`، الفرق في الناتج يساوي ثلاثة أضعاف فرق المدخل، فنختار `δ=ε/3`.

## جرّب بنفسك

```try python
from fractions import Fraction

a = 2
epsilon = Fraction(3, 10)
delta = epsilon / 3
x = a + delta / 2
print(delta)
print(abs((3 * x + 2) - (3 * a + 2)) < epsilon)
```

```exercise
? لو ε=0.6 في المثال، فما قيمة δ حسب القاعدة؟ اكتبها عشريًا.
___
= 0.2
```

```quiz
? ماذا يحدث لفرق الناتج لو كان فرق المدخل أقل من δ؟
- يساوي ε دائمًا
* يكون أقل من ε
- يكون أكبر من ε
> فرق الناتج يساوي ثلاثة أضعاف فرق المدخل، وأقل من 3δ=ε.
```

# @lesson complex-analysis-contours
title: مشروع: التكامل حول دائرة
summary: للتكامل حول دائرة نصف قطرها 1 عكس عقارب الساعة، نضع `z(t)=exp(it)` من 0 إلى `2π`.
---
للتكامل حول دائرة نصف قطرها 1 عكس عقارب الساعة، نضع `z(t)=exp(it)` من 0 إلى `2π`. لدالة `1/z` يصبح `z′(t)/z(t)=i`، فيساوي التكامل `2πi`. قارن بتكامل دالة `z` على نفس المسار، والذي يساوي صفرًا لأن لها دالة أصلية `z²/2`.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from cmath import exp
from math import tau

count = 128
step = tau / count
points = [exp(1j * (i + 0.5) * step) for i in range(count)]
for function in (lambda z: 1 / z, lambda z: z):
    integral = sum(function(z) * (1j * z) * step for z in points)
    print(round(abs(integral), 6))
```

```exercise
? ما الجزء الحقيقي من التكامل 2πi؟
___
= 0
```

```quiz
? ما نتيجة التكامل حول الدائرة للدالة z؟
- 2πi
* 0
- 1
> مسار الدائرة مغلق، ودالة z لها دالة أصلية تُعطي فرقًا صفرًا بين طرفي المسار.
```

# @lesson complex-residues-cauchy
title: مبرهنة كوشي وصيغة التكامل
summary: لدالة تحليلية على قرص وجواره، تكاملها حول حد القرص صفر.
---
لدالة تحليلية على قرص وجواره، تكاملها حول حد القرص صفر. ولو وضعنا في المقام `z−a` حيث a داخل الدائرة، صيغة كوشي تعطي `∮ f(z)/(z−a) dz = 2πi f(a)`. المثال يقارن الحالتين لدالة `z²` عند a=0.5.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from cmath import exp
from math import tau

count = 128
step = tau / count
points = [exp(1j * index * step) for index in range(count)]
for f in (lambda z: z ** 2, lambda z: z ** 2 / (z - 0.5)):
    integral = sum(f(z) * 1j * z * step for z in points)
    print(round(abs(integral), 3))
```

```exercise
? ما قيمة f(a) إذا كان f(z)=z² وa=0.5؟ اكتبها عشريًا.
___
= 0.25
```

```quiz
? ما الذي يضيفه المقام z−a عندما f(a) غير صفرية؟
* قطبًا بسيطًا عند a
- صفرًا عند a
- ثابتًا حقيقيًا فقط
> المقام ينعدم خطيًا عند a بينما البسط لا ينعدم.
```

# @lesson complex-residues-laurent
title: متسلسلات لوران
summary: في حلقة حول المركز، متسلسلة لوران تسمح بأسس سالبة إلى جانب الأسس غير السالبة.
---
في حلقة حول المركز، متسلسلة لوران تسمح بأسس سالبة إلى جانب الأسس غير السالبة. مثال `1/[z(1−z)] = 1/z + 1 + z + z² + …` عندما `0<|z|<1`. المجال مهم لأن المتسلسلة الهندسية في z تحتاج مقدارًا أقل من واحد.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
z = 0.5
exact = 1 / (z * (1 - z))
for count in (2, 8):
    partial = 1 / z + sum(z ** k for k in range(count))
    print(round(partial, 4), exact)
```

```exercise
? ما معامل 1/z في المثال؟
___
= 1
```

```quiz
? هل يتقارب هذا التوسع عند z=2؟
- نعم
```

فضاء هيلبرت كامل بالنسبة لمعيار ناتج من جداء داخلي. في `L²` على `[0,1]`، الجداء الداخلي لدالتين حقيقيتين هو تكامل حاصل ضربهما، والدوال المتساوية تقريبًا في كل مكان تُعامل كعنصر واحد. لإسقاط x على الدوال الثابتة نأخذ متوسطه 1/2، فيصبح تكامل الباقي صفرًا.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from fractions import Fraction

count = 16
samples = [Fraction(2 * i + 1, 2 * count) for i in range(count)]
projection = sum(samples) / count
print(projection)
print(sum(x - projection for x in samples) / count)
```

```exercise
? ما معامل إسقاط 2x على الثوابت في [0,1]؟
___
= 1
```

```quiz
? ما الجداء الداخلي للباقي مع الدالة الثابتة 1 بعد الإسقاط؟
- 1/2
- 1
* 0
> الإسقاط المتعامد يترك باقيًا متعامدًا مع فضاء الثوابت.
```

# @lesson advanced-math-categories
title: نظرية الفئات
summary: تدرس نظرية الفئات الكائنات والأسهم وطريقة تركيبها.
---
تدرس نظرية الفئات الكائنات والأسهم وطريقة تركيبها. في مثال مألوف، المجموعات هي الكائنات والدوال بينها هي الأسهم. لكل مجموعة دالة هوية. التركيب تجميعي: لما الأنواع تتوافق، `h ∘ (g ∘ f)` يساوي `(h ∘ g) ∘ f`، والصيغتان تطبّقان f ثم g ثم h.

لو محتاج مراجعة، ارجع لدرس [[math-functions-trig-ar/functions-rule|مدخلات الدالة ومخرجاتها]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
def compose(g, f):
    return lambda x: g(f(x))

def f(x):
    return x + 1

def g(x):
    return 2 * x

def h(x):
    return x - 3

left = compose(h, compose(g, f))
right = compose(compose(h, g), f)
print(left(4), right(4))
```

```exercise
? لو f(x) = x + 1 وg(x) = 2x، فما قيمة (g ∘ f)(3)؟
___
= 8
```

```quiz
? أي دالة تمثل الهوية على مجموعة الأعداد الصحيحة؟
* x ↦ x
- x ↦ x + 1
- x ↦ 0
> دالة الهوية تعيد المدخل نفسه لكل عدد.
```

# @lesson category-theory-functor
title: مشروع: مؤثر يحفظ التركيب
summary: المؤثر الفئوي ينقل الكائنات والأسهم ويحفظ الهوية والتركيب.
---
المؤثر الفئوي ينقل الكائنات والأسهم ويحفظ الهوية والتركيب. مؤثر مجموعة الأجزاء ينقل كل مجموعة إلى مجموعة أجزائها، وينقل كل دالة إلى عملية أخذ صورة مجموعة جزئية. صورة جزء تحت `g∘f` تساوي صورة صورته تحت f ثم g.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم لاختبار الفكرة.

```try python
def image(function, subset):
    return {function(value) for value in subset}

subset = {1, 2}
f = lambda x: x + 1
g = lambda x: 2 * x
separate = image(g, image(f, subset))
composed = image(lambda x: g(f(x)), subset)
print(sorted(separate), separate == composed)
```

```exercise
? كم عنصرًا في صورة {1,2} تحت x ↦ 2x؟
___
= 2
```

```quiz
? ما الخاصيتان اللتان يحفظهما المؤثر الفئوي؟
- الترتيب العددي دائمًا
- كل حجم مجموعة
* الهوية والتركيب
> المؤثر يرسل الهوية لهوية، وتركيب سهمين لتركيب صورتيهما.
```
