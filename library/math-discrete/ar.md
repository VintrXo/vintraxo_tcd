# @lesson discrete-math-logic
title: المنطق وجداول الصدق
summary: العبارة المنطقية لها قيمة صدق.
---
العبارة المنطقية لها قيمة صدق. يكون `A and B` صادقًا عندما تصدق العبارتان، ويكون `A or B` صادقًا إذا صدقت واحدة على الأقل. تُبدّل `not` قيمة الصدق.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from itertools import product

for a, b in product((False, True), repeat=2):
    print(a, b, a and b, a or b)
```

```exercise
? كم مرة يكون A or B صحيحًا في جدول الصدق؟
___
= 3
```

```quiz
? كم حالة تجعل A and B صادقًا؟
* 1
- 2
- 3
> الحالة الوحيدة هي أن تكون القيمتان صادقتين.
```

# @lesson discrete-math-routes
title: مشروع: أقل عدد محطات
summary: نمثل المحطات كعُقد والخطوط كحواف.
---
نمثل المحطات كعُقد والخطوط كحواف. إذا كان لكل انتقال نفس التكلفة، نبحث بالمستويات: نزور القريب أولًا، ثم جيران المستوى التالي. سجّل أول مسافة لكل محطة حتى لا تعيد زيارة المحطات عند وجود دورة.

## جرّب بنفسك

توقّع الناتج، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from collections import deque

network = {'A': ['B', 'C'], 'B': ['A', 'D'], 'C': ['A', 'D'], 'D': ['B', 'C', 'E'], 'E': ['D']}
distance = {'A': 0}
queue = deque(['A'])
while queue:
    current = queue.popleft()
    for neighbour in network[current]:
        if neighbour not in distance:
            distance[neighbour] = distance[current] + 1
            queue.append(neighbour)

print(distance['E'])
```

```exercise
? كم انتقالًا من A إلى D بأقصر طريق في المثال؟
___
= 2
```

```quiz
? لماذا نسجّل أول مسافة لكل محطة؟
* حتى لا نزورها مرة ثانية عند وجود دورة
- حتى نحذف كل المسارات القصيرة
- حتى يصبح الرسم البياني موجهًا
> البحث بالمستويات يكتشف كل محطة أول مرة بأقل عدد انتقالات.
```

كمّل في درس الرسوم البيانية في كورس الخوارزميات.

# @lesson mathematical-proof-direct
title: البرهان المباشر
summary: لإثبات أن مجموع عددين فرديين زوجي، اكتب العددين `2a+1` و`2b+1`.
---
لإثبات أن مجموع عددين فرديين زوجي، اكتب العددين `2a+1` و`2b+1`. بجمعهما تحصل على `2(a+b+1)`، وهو ضعف عدد صحيح. التعويض بأي قيم في المثال يوضح البرهان لكل a وb.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
a, b = 3, -2
left, right = 2 * a + 1, 2 * b + 1
print(left, right, left + right)
print(2 * (a + b + 1))
```

```exercise
? إذا كان a = 4، فما العدد الفردي 2a+1؟
___
= 9
```

```quiz
? أي تعبير يبيّن أن المجموع زوجي مباشرة؟
* 2(a+b+1)
- a+b+1
- 2a+1
> وجود 2 عاملًا في عدد صحيح يثبت الزوجية.
```

## اكتب برهانًا

أثبت أن مجموع عدد زوجي وعدد فردي فردي.

:::tip راجع الحل بعد المحاولة
اكتب العددين `2a` و`2b+1`. المجموع `2(a+b)+1`، وهو فردي.
:::

# @lesson mathematical-proof-contrapositive
title: المقابل المعاكس
summary: لإثبات «إذا كان مربع n زوجيًا، فإن n زوجي»، أثبت «إذا كان n فرديًا، فإن مربعه فردي».
---
لإثبات «إذا كان مربع n زوجيًا، فإن n زوجي»، أثبت «إذا كان n فرديًا، فإن مربعه فردي». لو `n=2k+1`، فالمربع `2(2k²+2k)+1`. قلب اتجاه الشرط وحده يعطي العكس، وهو عبارة أخرى يجب إثباتها منفصلة.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
for n in (1, 3, 7):
    print(n, n * n, n * n % 2)
```

```exercise
? ما باقي قسمة مربع 5 على 2؟
___
= 1
```

```quiz
? ما المقابل المعاكس لعبارة: إذا صدقت P صدقت Q؟
- إذا صدقت Q صدقت P
* إذا لم تصدق Q فلا تصدق P
- إذا لم تصدق P فلا تصدق Q
> ننفي العبارتين ونبدّل دور الشرط والنتيجة.
```

## اكتب برهانًا

أثبت بالمقابل المعاكس أن n فردي إذا كان n³ فرديًا.

:::tip راجع الحل بعد المحاولة
لو n زوجي نكتبه `2k`، ومكعبه `8k³=2(4k³)` زوجي. ده المقابل المعاكس للمطلوب.
:::

# @lesson mathematical-proof-contradiction
title: البرهان بالتناقض
summary: نفترض عكس المطلوب، ثم نستنتج أمرًا يناقض حقيقة أو افتراضًا.
---
نفترض عكس المطلوب، ثم نستنتج أمرًا يناقض حقيقة أو افتراضًا. لإثبات عدم وجود أكبر عدد صحيح، افترض أن M هو الأكبر. العدد `M+1` صحيح وأكبر منه، فتتناقض النتيجة مع الافتراض.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
candidate = 1000
counterexample = candidate + 1
print(counterexample)
print(counterexample > candidate)
```

```exercise
? ما العدد الصحيح التالي لـ999؟
___
= 1000
```

```quiz
? ما الافتراض الذي أدى للتناقض في المثال؟
- إمكان جمع عددين صحيحين
- أن 1 عدد صحيح
* وجود أكبر عدد صحيح
> العثور على M+1 يناقض أن M أكبر الأعداد الصحيحة.
```

## اكتب برهانًا

استخدم التناقض لإثبات عدم وجود أصغر عدد صحيح.

:::tip راجع الحل بعد المحاولة
لو m هو الأصغر، فإن `m−1` عدد صحيح أصغر منه. ده يناقض الافتراض.
:::

# @lesson mathematical-proof-induction
title: الاستقراء الرياضي
summary: برهن أن مجموع أول n عدد فردي موجب يساوي `n²`.
---
برهن أن مجموع أول n عدد فردي موجب يساوي `n²`. عند n=1 المجموع 1. لو صحّت الصيغة عند k، أضف العدد الفردي التالي `2k+1` فتحصل على `k²+2k+1=(k+1)²`. الأساس وخطوة الانتقال معًا يغطّيان كل n موجب.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
k = 5
previous_sum = sum(range(1, 2 * k, 2))
next_odd = 2 * k + 1
print(previous_sum, next_odd, previous_sum + next_odd)
```

```exercise
? كم مجموع أول أربعة أعداد فردية موجبة؟
___
= 16
```

```quiz
? ماذا تضيف للانتقال من k إلى k+1؟
* 2k+1
- 2k−1
- k+1
> الحد الفردي رقم k طوله العددي 2k−1، والحد التالي يزيد 2.
```

## اكتب برهانًا

أثبت بالاستقراء أن مجموع أول n عدد زوجي موجب هو `n(n+1)`.

:::tip راجع الحل بعد المحاولة
عند n=1، المجموع 2. لو المجموع عند k هو `k(k+1)`، نضيف `2(k+1)` فنحصل على `(k+1)(k+2)`.
:::

```exercise
= 3
```

```quiz

- عندما يكون الباقي 5
> الباقي صفر يعني وجود خارج صحيح يحقق a=5q.
```

# @lesson number-theory-primes
title: الأعداد الأولية والتحليل
summary: العدد الأولي أكبر من 1 وقواسِمه الموجبة 1 والعدد نفسه.
---
العدد الأولي أكبر من 1 وقواسِمه الموجبة 1 والعدد نفسه. لو كان n مركبًا، فإن له عاملًا لا يتجاوز √n، لأن عاملين أكبر من الجذر يعطيان حاصل ضرب أكبر من n. بالقسمة المتكررة نحصل على العوامل الأولية مع تكرارها.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
value = 84
factor = 2
factors = []
while factor * factor <= value:
    while value % factor == 0:
        factors.append(factor)
        value //= factor
    factor += 1
if value > 1:
    factors.append(value)
print(factors)
```

```exercise
? ما أصغر عامل أولي للعدد 35؟
___
= 5
```

```quiz
? أي قائمة تمثل تحليل 18 إلى عوامله الأولية؟
- 2، 9
* 2، 3، 3
- 3، 6
> حاصل ضرب 2 و3 و3 هو 18، وكلها أولية.
```

# @lesson number-theory-euclid
title: إقليدس وهوية بيزو
summary: القاسم المشترك الأكبر لـa وb يساوي القاسم المشترك الأكبر لـb وباقي a عند القسمة على b.
---
القاسم المشترك الأكبر لـa وb يساوي القاسم المشترك الأكبر لـb وباقي a عند القسمة على b. بتتبّع المعاملات أثناء الخطوات نكتب القاسم في صورة `sa+tb`. المثال يبدأ بمعاملي a وb للوصول إلى هوية بيزو.

## جرّب بنفسك

احسب الناتج أولًا، ثم شغّل المثال وغيّر أحد المدخلات.

```try python
a, b = 30, 18
old_r, r = a, b
old_s, s = 1, 0
old_t, t = 0, 1
while r:
    quotient = old_r // r
    old_r, r = r, old_r - quotient * r
    old_s, s = s, old_s - quotient * s
    old_t, t = t, old_t - quotient * t
print(old_r, old_s, old_t)
print(old_s * a + old_t * b)
```

```exercise
? أوجد القاسم المشترك الأكبر للعددين 21 و14.
___
= 7
```

```quiz
? أي تركيب يعطي القاسم المشترك الأكبر لـ30 و18؟
- 30−18
- 30+18
* −30+2×18
> −30+36 يساوي 6، آخر باقٍ غير صفري في خوارزمية إقليدس.
```

# @lesson number-theory-inverse

تتطابق قيمتان بترديد m لو كان الفرق بينهما من مضاعفات m. معكوس a هو عدد x يحقق `ax ≡ 1` بترديد m، ويوجد بالضبط عندما يكون القاسم المشترك الأكبر لـa وm يساوي 1. تشرح هوية بيزو السبب.

```try python
modulus = 7
value = 3
inverses = [x for x in range(modulus) if value * x % modulus == 1]
print(inverses)
```

```exercise
? ما معكوس 2 بالضرب بترديد 5؟
___
= 3
```

```quiz
? هل للعدد 2 معكوس بالضرب بترديد 6؟
* لا
- نعم، 2
- نعم، 3
> القاسم المشترك الأكبر هو 2، وكل مضاعفات 2 تبقى زوجية بترديد 6.
```

# @lesson advanced-math-combinatorics
title: التوافقيات المتقدمة
summary: مبدأ الشمول والاستبعاد يصحح العدّ المكرر.
---
مبدأ الشمول والاستبعاد يصحح العدّ المكرر. عند عدّ اتحاد ثلاث مجموعات، اجمع أحجامها، ثم اطرح أحجام التقاطعات الثنائية، ثم أضف حجم التقاطع الثلاثي. كده العضو الموجود في المجموعات الثلاث يُحسب مرة واحدة.

لو محتاج مراجعة، ارجع لدرس [[math-discrete-ar/discrete-math-combinations|التباديل والتوافيق]].

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
numbers = range(1, 31)
a = {n for n in numbers if n % 2 == 0}
b = {n for n in numbers if n % 3 == 0}
c = {n for n in numbers if n % 5 == 0}
count = len(a) + len(b) + len(c)
count -= len(a & b) + len(a & c) + len(b & c)
count += len(a & b & c)
print(count, len(a | b | c))
```

```exercise
? لو كانت مجموعة فيها 8 عناصر والثانية 5 وبينهما عنصران مشتركان، فكم عنصرًا في الاتحاد؟
___
= 11
```

```quiz
? ماذا نفعل بحجم التقاطع الثلاثي بعد طرح التقاطعات الثنائية؟
- نطرحه مرة أخرى
- نتجاهله دائمًا
```

# @lesson graph-theory-weighted
title: مشروع: أقصر مسار بأوزان
summary: أقصر مسار حسب الوزن قد يحتوي على حواف أكثر من مسار مباشر.
---
أقصر مسار حسب الوزن قد يحتوي على حواف أكثر من مسار مباشر. خوارزمية ديكسترا تثبّت العقدة ذات أفضل مسافة مؤقتة وتحدّث جيرانها عندما تكون الأوزان غير سالبة. المثال يرجع المسافة من A إلى C.

## جرّب بنفسك

توقّع النتيجة، ثم شغّل المثال وغيّر إحدى القيم.

```try python
from heapq import heappop, heappush

graph = {'A': [('B', 2), ('C', 7)], 'B': [('C', 3)], 'C': []}
distances = {'A': 0}
queue = [(0, 'A')]
while queue:
    distance, vertex = heappop(queue)
    if distance != distances[vertex]:
        continue
    for neighbour, weight in graph[vertex]:
        candidate = distance + weight
        if candidate < distances.get(neighbour, float('inf')):
            distances[neighbour] = candidate
            heappush(queue, (candidate, neighbour))
print(distances['C'])
```

```exercise
? ما وزن المسار المباشر من A إلى C؟
___
= 7
```

```quiz
? ما أقصر مسار حسب الوزن في المثال؟
- A–C
- B–C
* A–B–C
> وزن A–B–C يساوي 2+3، أقل من 7 للمسار المباشر.
```
