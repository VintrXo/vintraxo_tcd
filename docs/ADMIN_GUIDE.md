# دليل المسؤول — منصة التعلّم VX

من سطح المكتب افتح أيقونة **VX**. القائمة الجانبية مقسّمة: المحتوى، الدورات، التقييم، المهارات والشهادات، الحوكمة، التقارير، الإعدادات.

## الأدوار
| الدور | ماذا يفعل |
|---|---|
| مسؤول التعلّم (TCD Administrator) | كل شيء، بما فيه الإعدادات والتكاملات والذكاء الاصطناعي |
| كاتب المحتوى | يكتب المحتوى والأسئلة ويرسلها للمراجعة |
| مراجع المحتوى | يراجع ويعتمد وينشر |
| المدرّب | دوراته ومتعلموه والتصحيح |
| المتعلم | البوابة فقط (بدون سطح المكتب) |

## إعدادات التعلّم
- تفعيل البوابة، اللغة الافتراضية، اشتراط المراجعة قبل النشر، صناديق الكود، مواقع الفيديو المسموحة، أنواع وأحجام الملفات.

## دورة حياة المحتوى
مسودة ← قيد المراجعة ← معتمد ← منشور ← مؤرشف. كل نشر يحفظ نسخة يمكن مقارنتها واسترجاعها.
المحتوى المقيّد يظهر فقط للأدوار المحددة في المساحة.

## الاختبارات
- بنك الأسئلة بأنواعه، والاختبار يأخذ أسئلة محددة أو عشوائية من تصنيف.
- **المدرّب يراجع إجابات الأكواد**: فعّله في الاختبارات المحتسبة، لأن نتيجة الكود تُحسب على جهاز المتعلم ويمكن التلاعب بها.
- أسئلة الذكاء الاصطناعي تُحفظ بحالة «يحتاج مراجعة» ولا تدخل أي اختبار قبل تغييرها إلى «تمت المراجعة».

## قواعد التدريب (التسجيل التلقائي والإلزامي)
- الهدف: دورة أو مسار (تسجيل، ويمكن جعله إلزاميًا مع موعد استحقاق) أو صفحة (تظهر في «أدلة خاصة بدورك»).
- الجمهور: أدوار، وفلاتر الموارد البشرية (القسم، المسمى، الشركة) — تحتاج ERPNext/HRMS وربط المستخدم بموظف نشط.
- تُطبّق عند الحفظ، وعند تعديل المستخدم أو الموظف، ويوميًا، وبزر **طبّق الآن**. لا تعيد فتح تسجيل ألغاه المسؤول.
- تقرير **الالتزام بالتدريب** يوضح الإكمال والتأخير لكل موظف.

## الحوكمة
- مسودة ← مراجعة ← اعتماد (المعتمِد المحدد) ← نشطة. كل اعتماد ينشئ نسخة جديدة ويطلب إقرارًا جديدًا من الجمهور.
- تذكير بالمراجعة قبل موعدها بأسبوع، وتنتهي الوثيقة تلقائيًا في تاريخ انتهائها.

## موصّلات التكامل
- رابط استقبال (HTTPS)، الأحداث المطلوبة، مفتاح توقيع، حد في الدقيقة، عدد المحاولات.
- **إرسال تجربة** للتأكد، و**سجل التكامل** لمتابعة كل حدث وإعادة المحاولة.
- الشبكة الخاصة ممنوعة إلا بتفعيل «السماح بالشبكة الخاصة» لخدمة داخلية موثوقة.

## الذكاء الاصطناعي (متوقف افتراضيًا)
1. إعدادات الذكاء الاصطناعي ← فعّل، اختر المزوّد والنموذج وأدخل مفتاح API.
2. حدد الميزانية الشهرية وحد الطلبات اليومية والأسعار (لحساب التكلفة).
3. الخصوصية: عدم إرسال المحتوى المقيّد، إزالة البريد والهواتف، وعدم حفظ نص الطلبات (افتراضيًا).
4. **سجل استخدام الذكاء الاصطناعي** يوضح كل طلب: المستخدم، الميزة، الرموز، التكلفة، المصادر.
- الدروس المكتوبة بالذكاء الاصطناعي تُحفظ **مسودة** وتمر بالمراجعة العادية قبل النشر.

## التقارير
تقدم المتعلمين، تحليل الاختبارات، لوحة المدرّب، فجوة الكفاءات، حالة الإقرارات، تقرير الدورات، استخدام المعرفة، نظرة على الالتزام، الالتزام بالتدريب.

## النسخ الاحتياطي
`bench --site <site> backup --with-files` — راجع دليل النشر للاستعادة.
